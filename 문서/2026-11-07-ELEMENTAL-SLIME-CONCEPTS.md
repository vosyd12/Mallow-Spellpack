작업일: 2026-11-07. 사용자는 불·물·땅·바람·번개·무속성 각각에 Small·Medium·Large를 준비하되, Prefab 제작 전 이미지부터 검토하기를 요청했다. Small은 미세한 디테일 때문에 작게 보았을 때 어색하다는 피드백도 반영했다.

이미지는 몸·얼굴·장식이 합쳐진 단일 포즈의 검토용 PNG다. 기존 게임 이미지를 교체하거나 Prefab을 추가하지 않았다. 현재 활성 공통 아틀라스와 얼굴 지연 흔들림·그림자·먼지·파동은 그대로다.

## 문제·선택·변경

이전 개별 생성에서는 픽셀 윤곽·명암·얼굴 표현에 편차가 있었다. 이번에는 공통 `SlimeStyleAtlas.png`를 기준으로 크기별 무속성 시안을 먼저 만들고, 그 시안을 편집 대상으로 색과 속성 장식만 변경했다. 서로 다른 속성에서도 기본 얼굴과 몸의 인상이 이어지도록 한 선택이다. 생성 이미지는 공통 기준을 사용한 시안이며 픽셀 단위로 동일한 원본을 복제한 결과는 아니다.

| 속성 | 색상 방향 | Small → Medium → Large 장식 |
| --- | --- | --- |
| 무속성 | 민트 | 기본 몸, 크기별 홍조·눈썹·콧수염 |
| 불 | 주황·다홍 | 불씨 하나 → 갈라진 불꽃 → 넓은 불꽃 갈기 |
| 물 | 파랑·청록 | 물방울 → 물결 앞머리 → 파도 테두리 |
| 땅 | 모래·갈색 | 조약돌 하나 → 양옆 돌·간단한 균열 → 바위 장식·굵은 이음선 |
| 바람 | 옅은 민트·백색 | 휘어진 바람 머리 → 소용돌이 앞머리 → 구름 테두리·바람 무늬 |
| 번개 | 노랑·보라 | 지그재그 하나 → 갈라진 번개 → 번개 왕관·전류 무늬 |

Small은 풍성하고 단순한 몸, 작은 미소·홍조, 큰 속성 장식 하나를 우선했다. 미세한 금·입자·복잡한 내부 무늬는 넣지 않도록 지정했다. Medium은 한쪽 눈썹, Large는 콧수염을 보존해 색상 외에도 크기별 성격이 읽히도록 했다.

## Small 크기와 후속 연결

현재 게임의 Small은 변경하지 않았다. 실제 표시 크기를 약 20% 늘리는 안은 프리팹 적용 때 검토할 제안값이다. 이미지의 해상도나 갤러리 표시 크기는 게임의 월드 크기를 뜻하지 않는다. Medium·Large는 현재 표시 크기를 유지하는 방향이다.

후속 작업에서는 검토한 속성 장식을 제작용 레이어로 분리하고 공통 몸·얼굴 구조에 연결해야 한다. 단일 PNG로 바로 교체하면 현재 얼굴 지연 흔들림을 그대로 활용할 수 없으므로, 18개 완성 Prefab이나 속성 기능을 구현한 것으로 표시하지 않는다. 전투 효과·상성·피해 계산은 별도 결정이 필요하다.

## MCP 선택과 확인 결과

이번 단계의 주 작업은 이미지 생성과 파일 정리이므로 Unity MCP 연결 없이 진행했다. Unity의 프리팹 연결·화면 배치 검증은 이후 MCP가 도움이 되는 단계다. 속도를 측정해 비교한 결과는 아니다.

생성 결과에서 얼굴과 속성 장식의 구성을 확인했고, 파일 검사로 18개 조합·정사각 RGBA PNG·투명 배경·원본 링크를 확인했다. 프롬프트와 파일 지문을 저장했다. 갤러리의 실제 브라우저 표시, Unity 임포트·Play Mode·모바일 성능은 검증하지 않았다.

이 작업은 Assets 파일에 쓰지 않았다. 작업 중 `EnemyState.cs`의 `Pure` 추가가 감지되어 그대로 보존했으며, 전체 코드가 작업 시작 때와 동일하다고 보고하지 않는다. 속성 식별자 선언과 게임 기능 구현은 구분한다.
