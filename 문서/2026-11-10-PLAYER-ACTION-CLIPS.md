# 플레이어 Attack·피격·사망 클립 단독 제작

작성일: 2026-11-10. 사용자가 승인한 동작으로 애니메이션 클립만 제작했다. C#·씬·Prefab·Animator Controller·기존 Idle/Walk·원본 Sprite는 변경하지 않았다. MCP·Notion은 사용하지 않았다.

후속: [플레이어 Controller 상태 등록](2026-11-10-ANIMATION-WIRING.md)을 진행했다. Walk·Attack·Hit·Death에 클립은 연결됐지만 실제 재생 호출은 아직 없다. 아래 Controller가 Idle 한 상태라는 설명은 초기 제작 시점의 기록이다.

## 문제·원인·선택한 보정

- 초안의 큰 팔 회전과 몸통 비틀림에서 원화 분리 경계가 벌어졌다. 기존 이미지와 Prefab을 유지하기 위해 공격 팔 회전을 ±8도로 줄이고 불필요한 개별 비틀림을 제거했다. 모자·머리는 작은 후행 동작으로 보완했다.
- 입을 납작하게 줄이면 Head에서 잘라낸 입 영역이 노출됐다. 입의 기존 영역을 덮도록 약간 벌리는 반응으로 변경했다. 새 표정 Sprite를 그리거나 원본 PNG를 수정하지 않았다.
- 사망은 개별 팔다리 애니메이션 대신 묶음의 위치·회전만 변화시킨다. 중심점을 보정해 한 덩어리로 날아가도록 했다. 기본 자세 외의 실제 사망 순간 자세를 포착하는 연결은 이번 범위가 아니다.

- 기존 C#·씬·Prefab·Animation·Sprite 파일 해시가 작업 전후 일치했다. 새 클립·미리보기·문서만 추가·갱신했다.

## 남은 범위

현재 게임 Controller는 여전히 Idle만 사용한다. Attack 발사 시점·피격 호출·HP 0·상태 전환·사망 후 화면 처리는 연결하지 않았다. HitStop·Bloom·피격 그라데이션도 추가하지 않았다.

사망 클립은 제작한 고정 경로로 미리보기 화면을 이탈한다. 모든 게임 화면 비율에서의 이탈 판정·사망 순간 자세 유지가 연결된 것은 아니다. 지금은 애니메이션만 검토하며 해당 코드 작업은 이후 별도 요청으로 진행한다.

## 후속 Death 수정과 Attack 검토

사용자는 Attack이 어색하고 Death의 회전이 부족하다고 평가하며 쿠키런: 크럼블의 사망 장면을 참고하도록 요청했다. Attack은 팔·지팡이의 작은 회전 위주여서 앞으로 내미는 동작과 힘의 차이가 약하다. 파츠 경계를 보존하는 데 치우쳐 공격 가독성 확인이 부족했다. 이번에는 문제를 기록하고 Attack 클립은 유지했다. 손·지팡이의 전후 위치 변화와 준비/내밀기/복원의 강약 보완은 다음 조정 대상이다.

참고 자료는 [공식 PV](https://www.youtube.com/watch?v=6a0YPdUQAgM)와 [TargoGaming 공개 플레이 영상 약 1:07](https://www.youtube.com/watch?v=eL_fBwsu6qs&t=67)이다. PV는 장면이 작고 빠르게 편집되어 개별 사망 동작 판독에 한계가 있었다. 플레이 영상의 66.5~68.5초를 프레임으로 나눠, 적 처치 후 몸 전체가 회전하며 위쪽·뒤쪽으로 튕겨 나가는 모습을 확인했다. 쿠키 사망과 모든 적 유형을 확인한 것은 아니다. [확인한 프레임](플레이어ActionV3/ReferenceDeathFrames.png)

기존 Death는 1.10초에 300도여서 한 바퀴도 회전하지 않았고, 포물선 높이도 낮았다. 새 클립은 **0.90초·1080도·3회전**으로 바꾸고 도약 높이를 늘려 가볍게 튕기는 인상을 강화했다. 로컬 이동은 `x=6u`, `y=6u-6.5u²`이고 `u=시간/0.9`다. 회전·시간·궤적은 프로젝트의 조정값이며 참고 영상에서 측정한 수치가 아니다. 플레이 영상의 왼쪽 이탈을 그대로 복제하지 않고 이번 클립은 기존 오른쪽 방향을 유지한다.

파츠별 자세는 고정한 채 전체만 이동·회전하며, 181시점의 파츠 로컬 변형 오차는 약 0.000000005다. Attack·Hit·Idle·Walk·기존 코드·씬·Prefab·Controller·Sprite는 수정 전후 해시가 일치했다. 수정 전 미리보기는 [이전 Death](플레이어ActionV3/BeforeRevision_Death.gif)로 보존했다. 새 미리보기의 회전·포물선을 확인하고, 수정된 클립의 별도 Unity 임포트 로그도 갱신했다. 게임 실행과 상태 연결은 이번 수정에도 포함하지 않았다.
