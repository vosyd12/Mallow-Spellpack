# 모바일 수동 이동 연결

사용자가 작성한 `Player.cs`의 수동 이동은 공용 입력 에셋의 `Player/Move`를 읽는다. 모바일 드래그가 같은 액션에 전달되도록 `Assets/Scenes/IngameScene.unity`의 `HUDCanvas` 아래에 `MovementJoystick`을 추가했다.

- 손잡이의 `OnScreenStick`은 `<Gamepad>/leftStick`으로 동작한다. 중심은 고정하고 첫 접촉 지점에서 손가락이 이동한 방향과 크기를 입력한다. 이동 범위는 Canvas 기준 47이다.
- 넓은 터치 영역을 사용하고 조이스틱을 다른 HUD 패널 아래에 배치했다. 하단 스킬 버튼을 누를 공간을 확보했다.
- Unity 6000.5.10f1의 격리 사본에서 씬을 저장하고 다시 열었다. Play Mode에 가상 터치와 키보드 이벤트를 보내 드래그 이동, 손잡이 복귀, 입력 해제 후 정지, 걷기·대기 전환, W+D 대각선 이동, 자동 기본 공격 시작을 확인했다.
- 375×808과 450×970에서 조이스틱이 화면 안에 있고 스킬 슬롯과 겹치지 않는 것을 확인했다. 검증한 씬과 작업 폴더에 반영한 씬의 파일 해시가 일치한다. 실기기 터치와 긴 거리 이동 시 카메라 가시성은 추가 확인 범위다.
