# 2026-11-09 HUD 시안 외형 적용

## 범위와 변경

- SampleScene의 기존 상단 HUD에 크림색 패널·올리브 테두리·녹색 경험치 바·황금색 보스 게이지·작은 보스 아이콘을 적용했다.
- 캐릭터 이름, 레벨, 현재/필요 경험치, 수동 레벨업, Stage 번호, 보스 진행도 표시의 기존 참조와 버튼 이벤트를 유지했다.
- `Assets/UI/TopHUD/Skins/`에 투명 PNG 4종과 Sprite 분할 설정을 추가했다. 기존 도형 보스 아이콘의 자식은 비활성화했다.
- C# 소스 및 사용자 원본 UI 배치도는 변경하지 않았다. 작업 전 이미 존재하던 씬 편집 내용은 저장·보존했다.

## 문제 → 원인 → 해결

기존 단색 UI가 시안의 스타일과 달랐다. 기능 연결을 보존하면서 패널·게이지·아이콘만 교체하는 방법을 선택했다. 가져오기 중 원본보다 작은 텍스처 좌표로 Sprite를 나누면 오른쪽이 잘리는 문제가 확인되어, 원본 크기를 유지한 상태에서 분할하고 Simple 이미지로 배치했다. 바의 Fill은 기존 Horizontal Filled 설정을 유지한다.

## 실제 확인 결과

- 자동 공격과 적 생성을 유지한 일반 전투에서 경험치가 증가했다.
- 경험치 100에서 버튼의 포인터 클릭 처리를 실행해 `Lv. 1, 100 / 100 → Lv. 2, 0 / 110`을 확인했다. 물리 마우스 클릭 검증과는 구분한다.
- 실행 중 보스 진행도를 50%·100%로 지정해 Fill과 등장 안내를 확인하고 0으로 복원했다. 실제 보스 생성 검증은 아니다.
- 가로 화면과 720×1280 세로 화면에서 최종 외형을 확인했다. 시험 후 원래 Game View와 편집 모드로 복귀했다.
- C# 파일 해시 비교 결과 변경 0개. 콘솔 확인 시 오류·경고 0개. 최종 PlayerAttack·EnemySpawner 활성 상태와 씬 저장 상태를 확인했다.

## 남은 작업

- 골드는 StageInfo에 표시 필드만 있고 금액 전달·갱신이 없어 제외했다.
- 보스 진행도의 자동 증가 조건과 실제 보스 생성은 미연결이다.
- 하단 스탯·배낭·스킬·옵션 버튼 및 창은 동작 연결이 준비되지 않아 추가하지 않았다.
- 이름과 레벨업 버튼의 최종 위치는 미확정이다. 기존 한글 폰트는 제한된 글자만 포함하므로 새로운 이름을 사용할 때 글자 지원을 확인해야 한다.

## 후속 조정: 패널 축소·EXP 높이 확대

- 문제: Stage 패널의 빈 여백과 정보창 아래로 떨어진 버튼이 공간을 차지하고, EXP 숫자에 비해 바의 내부 높이가 작았다.
- 원인: 패널 높이와 내부 배치가 내용에 비해 컸고, 경험치 바의 테두리를 제외한 실제 표시 공간이 부족했다.
- 해결: Canvas 기준 캐릭터 패널 높이를 230→194, Stage 패널 높이를 200→148로 줄였다. Stage 폭도 화면 비율 56%→50%로 줄이고 제목·게이지·아이콘을 재배치했다. 레벨업 버튼은 캐릭터 패널 내부의 레벨 오른쪽으로 옮겨 공간을 활용했다.
- EXP 바 높이는 약 48→60으로 늘리고 내부 여백과 글자 크기를 조정했다. 빈 게이지에서도 숫자를 읽도록 밝은 글자와 작은 그림자를 적용했다. 신규 게임 로직은 추가하지 않았다.
- 확인: MCP로 최종 가로·720×1280 세로 화면을 확인했다. EXP 텍스트 넘침 없음, 버튼의 기존 TryLevelUp 연결 1개, 공격·적 생성 활성 상태, 씬 저장 완료, 콘솔 오류·경고 0개를 확인했다. 중단 전에 일반 전투에서 경험치 증가도 확인했다. 이번 조정 후 레벨업 클릭은 재시험하지 않았다.
- C# 소스 파일 해시 비교 결과 변경 0개다. MCP의 임시 C# 명령으로 씬의 UI 설정을 조정했으며 소스 파일 수정과 구분한다. 전투 겹침·골드·하단 메뉴는 변경하지 않았다. 기존 남은 작업은 유지한다.
