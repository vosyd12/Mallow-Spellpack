# 보스 등장 연출과 타이머

`IngameScene` 저장본의 `StageInfo`에는 새 연출에 필요한 참조가 비어 있었고, `Stage.prefab`의 카메라는 기본 왕복 동작을 사용했다. 기존 HUD와 C# 호출에 맞춰 Unity 에디터에서 프리팹과 애니메이션을 연결했다.

- `Assets/UI/TopHUD/BossEncounter/BossAnnouncement.prefab`은 보스 등장과 줌인 시작에 맞춰 `BOSS 등장`을 띄운다. 금빛 띠가 양옆으로 펼쳐지고 글자가 한 번 커졌다가 자리 잡은 뒤 사라진다.
- 같은 폴더의 `BossTimer.prefab`은 기존 체력바 위에 15초를 표시한다. 카메라 복귀 뒤 `StartCountdown`을 받아 15초 클립으로 위쪽 모래를 줄이고 아래쪽 모래를 채운다. 낙하 입자는 자식 Animator에서 반복하고 0초에 숨긴다. 타이틀·모래·입자의 자세와 타이밍은 Animation Clip에서 조정한다.
- `Assets/Prefab/Stage.prefab`의 카메라는 2초 안에 약 0.58초 접근, 0.40초 유지, 1.02초 복귀하도록 커브를 지정했다. 세로 화면에서 보스 머리 위의 체력바까지 보이도록 최대 줌 배율을 0.62로 잡았다.
- `Assets/Scenes/IngameScene.unity`의 `StageInfo`에는 타이틀 루트, 타이머 Animator, 숫자 텍스트를 연결했다. 기존 등장 텍스트는 Inspector에서 TMP 렌더링을 꺼 두었다. 현재 C# 포맷에 따라 시간은 `00: 15`처럼 콜론 뒤에 공백이 표시된다.

## 검증

- Unity 6000.5.10f1에서 Unity MCP로 `IngameScene`의 582×829 Game View를 확인했다. 처치 목표를 채운 뒤 타이틀, 최대 줌 유지, 원래 위치·크기로 복귀하는 흐름과 보스 체력바 위 타이머를 확인했다.
- Play Mode에서만 테스트 대상의 체력을 높여 15초 전체를 관찰했다. 인트로 중에는 숫자와 모래가 대기했고, 복귀 뒤 숫자가 줄면서 모래알이 떨어졌다. 0초에 모래알이 멈췄고, 이후 보스 처치 시 타이머가 숨겨지고 2스테이지로 넘어갔다.
- 별도 Play Mode에서 등장 연출 중 플레이어 사망을 유도했다. 카메라가 복구되고 타이틀·타이머와 보스가 정리됐으며 1스테이지에서 플레이어가 부활했다. 검증 종료 시 MCP 콘솔에서 오류를 찾지 못했다.
