# 캐릭터 레벨업 연출 롤백

카드 작업을 이어갈 때는 이후 파일 이름 변경을 반영한 최신 인수인계를 확인한다. [레벨업 카드 인수인계](2026-11-22-LEVEL-UP-CARD-HANDOFF.md)

- **확정** — 레벨업 버튼 입력 직후 카드가 열리도록 방향을 정했다. 카드 자체가 레벨 상승과 다음 행동을 알려준다. 캐릭터 쪽에서 먼저 연출을 재생하면 버튼 입력에서 카드 선택까지 기다리는 단계가 추가돼 빛 기둥과 머리 위 문구를 롤백했다.
- **적용** — `IngameScene`의 `Player`에서 `LevelUpEffect` 인스턴스와 `PlayerLevelUpEffect` 컴포넌트 연결을 제거했다. 전용 프리팹·클립·컨트롤러·머티리얼·텍스처와 각 메타는 `Temp/LevelUpEffectRollback-20261122`로 옮겼다.
- **기존 레벨업 연결** — 버튼 클릭 애니메이션, `Player.TryLevelUp()`의 경험치 차감과 HUD 갱신, `LeveledUp` 이벤트를 그대로 사용한다. `PlayerLevelUpEffect.cs`는 사용자 작성 파일로 보관한다.
- **검토 중** — 카드 후보 수와 강화 범위, 선택 중 전투 처리, 강화 선택 뒤 슬롯 피드백의 방식.

## 다음 작업 인수인계

- **결정** — 캐릭터 연출을 롤백하고 카드 등장으로 레벨업 성공을 표현한다.
- **적용** — 캐릭터 연출을 씬에서 분리하고 전용 에셋과 메타를 복구용으로 옮겼다.
- **검증** — 현재 `IngameScene`이 캐릭터 연출 적용 직전 파일과 일치하고, `Assets`에 보관한 연출 GUID를 참조하는 파일이 없음을 확인했다. Unity 6000.5.10f1의 복제 씬 Play Mode에서 캐릭터 연출 연결이 없는 상태로 연속 레벨업 두 번을 실행했다. 경험치 차감, 성공 이벤트, 버튼 크기 반응과 입력 영역을 확인했다.
- **다음 작업** — `LeveledUp`을 카드 패널의 열기 신호로 연결한다. 카드 후보와 보상 규칙은 착수할 때 정한다.
- **공유 기준** — 로컬에서 확인한 `origin/main`은 `4eb993e`다. 씬 롤백과 문서 변경은 작업 폴더에 있다.
