# 보스전 연결과 작업 인수인계

## 확정한 규칙

- 1스테이지의 보스 등장 목표는 일반 적 30마리다. 보스를 처치하고 다음 스테이지에 진입할 때마다 목표가 1마리씩 올라가며 100마리에서 멈춘다.
- 게이지가 가득 차면 일반 적과 탄환을 정리하고 보라색 몸과 금빛 왕관의 슬라임 보스 한 마리를 자동으로 생성한다. 보스전 동안 일반 적을 추가 생성하지 않는다.
- 보스 쪽으로 줌인하고 원래 구도로 돌아오기까지 **총 2초**를 사용한다. 이전 1초 설정을 대체한다. 복귀 뒤 전투를 재개하고, 기존 등장 게이지는 보스 생성 시 체력바로 바꾼다.
- 대형 슬라임의 공격·사망 클립을 공유한다. 보스 HP가 0이 되면 게이지도 0을 표시하고, 사망 모션이 끝나면 다음 스테이지로 넘어간다.
- 마지막 일반 적 처치와 플레이어 사망이 겹치면 재시작을 우선한다. 같은 스테이지를 다시 시작할 때 처치 수와 게이지가 0으로 돌아간다. 해당 스테이지의 목표와 플레이어 성장 정보는 유지한다.
- **보류** — 스킬창·스탯창을 열어도 게임은 진행한다는 방향을 유지한다. 창과 보스 등장 연출이 겹치는 경우의 시작 조건과 UI 처리는 해당 창을 구현한 뒤 결정한다.

## 검증 결과와 남은 확인

- **Unity Play Mode** — Unity 6000.5.10f1의 격리된 `IngameScene`에서 1초 카메라 설정으로 보스 한 마리 등장, 카메라 복귀 후 전투 시작, 체력바 감소, 착지 공격 피해 5, 사망 모션 후 2스테이지 진입과 목표 31을 확인했다. 마지막 처치와 플레이어 사망을 같은 프레임에 일으켰을 때 보스 없이 2스테이지로 재시작했고 목표 31을 유지했다. 착지 피해 검증에서는 플레이어 자동 공격을 끄고 공격 범위 안에 배치했다.
- **최신 2초 설정** — `Stage.prefab`의 `_bossIntroDuration = 2`와 `IngameScene`의 프리팹 상속을 파일에서 확인했다. 2초의 실제 재생과 자유 전투에서의 카메라 구도·착지 피해 거리는 검토 중이다.
- **검토 중** — `RestartRoutine()`에서 화면 덮기나 밝히기가 실패하면 재시작 잠금이 남는다. 화면 전환이 실패해도 같은 스테이지를 한 번 재구성하고 암전 오버레이와 잠금을 해제하는 보완을 검토한다.
- **검토 중** — `Enemy.Die()`에 사망 모션 구독자가 없으면 완료 알림 없이 적이 제거된다. 현재 보스가 이 분기를 타면 게이지가 만충으로 남아 보스가 다시 나올 수 있다. 즉시 제거 전에 `NotifyDeathMotionFinished()`를 연결하는 방안을 검토한다. 정상 보스 프리팹의 사망 모션 종료 경로는 Play Mode에서 확인했다.

## 함께 확인한 작업

- **화염 장판** — 여덟 갈래 불씨의 시차 수렴, 중앙 점화와 확장 고리, 테두리부터 옅어지는 2초 연출을 연결했다. `IngameScene`의 피해 설정은 반경 1.5, 지속 2초, 피해 간격 0.5초다. 매 피해 시점에 원과 콜라이더가 겹친 활성 적 모두에 피해를 주며 같은 적의 여러 콜라이더는 한 번으로 센다. 대상 수 제한은 없다. 전투가 시작된 뒤 보스도 같은 판정을 받는다. 이번 피해 범위 확인은 코드와 씬 파일을 기준으로 했다.
