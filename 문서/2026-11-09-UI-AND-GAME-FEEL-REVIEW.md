# UI·연출 통일과 기본 재미 개선 검토

작성일: 2026-11-09. 지금까지 논의한 문제와 제안을 정리한 **미적용 검토 문서**다. 문서화 승인을 실제 구현 승인이나 세부 기획 확정으로 해석하지 않는다.

## 범위와 판단 근거

미구현 기능을 제외하고도 현재 화면이 밋밋하다는 사용자 의견에서 출발한다. 폰트·이미지의 품질 편차, 화면 구성과 연출, 반복 전투를 관찰하는 재미를 함께 검토한다. 전투 중 겹침 개선은 이번 범위에서 제외한다.

화면에 관한 평가는 앞서 확인한 HUD·전투 화면의 인상이며 객관적인 품질 측정이나 플레이테스트 결과가 아니다. 이번에는 로컬 코드와 기존 문서를 확인했으며 MCP 재연결·새 실행 검증은 하지 않았다. 아래 원인은 확인된 구조와 추정 원인을 구분한다.

## 원초적인 재미에 대한 검토

현재 반복은 적 접근 → 자동 공격 → 처치 → 경험치 획득 → 수동 레벨업이다. 이 과정이 작동한다는 사실만으로 계속 보고 싶은 재미가 확보되지는 않는다. 다음은 대화에서 제기한 **가설**이며 재미 부족의 원인이 검증됐다는 뜻은 아니다.

- **관찰할 변화:** 공격과 처치가 반복될 때 무엇이 달라졌는지 읽히는가? 기존 속성 차이는 외형·착지 표현 수준에서 먼저 평가한다. 미구현 전투 효과를 이미 있는 차이처럼 설명하지 않는다.
- **성장의 의미:** 레벨 숫자 외에 플레이가 달라지는 이유가 있는가? 현재 스탯 상승이 없다는 점을 전제로, 실제 보상 규칙이 필요한지와 표시만 부족한지를 따로 판단한다.
- **기대할 순간:** 다음 처치·EXP 충족·레벨업을 기다릴 이유가 보이는가? 보스 등장처럼 아직 연결되지 않은 기능을 현재 재미의 근거로 사용하지 않는다.
- **내 선택의 결과:** 장기적으로 자신이 구성한 마법과 배낭 시너지가 전투를 바꾸는 것을 관찰하는 방향이 논의됐다. 현재는 미래 기획이며 이번 개선의 필수 구현 조건으로 삼지 않는다.

장식과 효과를 늘리면 시각적 인상은 좋아질 수 있지만 반복 전투의 심심함이 해결된다고 보장할 수 없다. 방치형 메인·뱀서류 서브라는 방향에서 평소에는 편안하게 관찰하고, 의미 있는 변화는 분명하게 읽히도록 하는 접근을 제안한다. 전투 규칙·속도·보상 수치는 미정이다.

## 권장 진행 순서와 확인 방법

1. **시각 기준 선정:** 현재 캐릭터·HUD·아이콘·폰트를 같은 화면에서 비교하고 선·색·명암·글자 위계의 기준을 선택한다. 전체 에셋을 먼저 교체하지 않는다.
2. **대표 화면 정리:** 캐릭터 정보창과 Stage 영역부터 통일감을 비교한다. 이미 완료한 패널 축소·EXP 확대를 미구현으로 되돌려 기록하지 않는다.
3. **기존 행동 하나씩 개선:** 명중, 처치, EXP 획득·레벨업 중 작은 범위를 골라 전후를 비교한다. 여러 효과를 한꺼번에 추가하지 않는다.
4. **재미와 품질을 별도 평가:** 같은 화면 크기·전투 조건에서 주요 정보가 읽히는지, 변화가 느껴지는지, 조금 더 관찰할 이유가 있는지를 사용자에게 확인한다. 시각적 호감과 전투 재미의 평가는 구분한다.

모든 효과의 시간·강도·폰트 크기는 아직 확정하지 않았다. 개선 전후 동일 조건에서 비교하고, 성능은 측정값으로 판단한다. 과거 FPS 저하 보고가 있으므로 효과·상시 애니메이션 증가를 무조건 최적화로 간주하지 않는다.

## 기존 요청·미구현 기능과의 관계

- 표정·사망·착지·대형 얼굴 위치·풀숲·성능 과제는 [기존 8개 요청](2026-11-09-PRESENTATION-AND-PERFORMANCE-TODO.md)을 기준으로 유지한다. 이 문서는 화면 전체의 문제와 우선순위를 보완하며 기존 요청을 대체하거나 완료 처리하지 않는다.
- 골드, 스탯 구매·환급, 배낭 뽑기·시너지, 마법 형태 1칸·특성 2칸과 해금, 하단 창·버튼 상호작용은 별도 기획이다. 기존 시안은 구현 증거가 아니다.
- 전투 중 겹침은 이번 검토의 개선 대상으로 추가하지 않는다. 앞서 적용한 가림 설정도 변경하지 않는다.
- 이 문서 작성으로 코드·씬·이미지·폰트·Animation은 바뀌지 않았다. 실제 개선 효과나 재미 향상은 아직 확인하지 않았다. 확정 규칙은 GAME_DESIGN에 임의로 추가하지 않는다.
