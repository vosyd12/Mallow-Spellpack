# 전투와 성장 시스템 통합 인수인계

> 수동 이동을 적용하기 전의 기록이다. 현재 코드·씬과 작업 우선순위는 [수동 조작과 던전 인수인계](2026-11-24-MANUAL-COMBAT-AND-DUNGEON-HANDOFF.md)를 확인한다.

현재 작업 씬은 `Assets/Scenes/IngameScene.unity`이며 Unity 버전은 `6000.5.10f1`이다. 자동 전투에서 처치·성장·보스전·다음 스테이지까지의 흐름을 연결했다. 다음 작업에서는 이미 만든 연출을 유지하고, 새 시스템은 발동과 결과가 읽힐 정도로 표시한 뒤 게임에서 확인한다. 첫 보스 이후 전투가 반복되는 문제는 카드 보상과 스킬 트리의 실제 성장 선택으로 보강하는 방향이다.

## 대화에서 정한 방향과 후속 과제

- **확정** — 기존 보스·카드 등 연출은 유지한다. 앞으로 추가하는 기능에는 상태를 읽을 수 있는 기본 표시만 먼저 넣는다. C#은 게임 상태·판정·시작과 종료 신호를 맡고, 프리팹 내부의 시각 요소·커브·키프레임은 Unity에서 조정한다.
- **검토 중** — 다음 큰 시스템은 번개 스킬보다 스킬 트리를 먼저 진행하는 방향이다. 카드 강화는 스킬 레벨, 트리 해금은 동작을 바꾸는 효과로 나누는 안을 검토한다. 소수 노드와 보스 처치 1포인트는 제안으로 남긴다. 포인트 지급·초기 노드·효과·보존 규칙은 아직 확정하지 않았다.
- **검토 중** — 플레이어와 Enemy의 머리 위 체력바는 피격 때만 표시하도록 공통 동작을 추가한다. 표시 시간·연속 피격 처리는 검토 중이다. 스테이지 중앙 타이틀은 기존 보스 타이틀 스타일을 재사용하고, 첫 입장·다음 입장·재시작 중 재생할 시점을 정한다. 자동 전투의 대상 선택·거리 유지·공격 전환 개선도 후속 과제다.
- **보류** — 스킬 트리 기본 기능을 확인한 뒤 번개 슬롯·카드 보상, 캐릭터 외형·리깅·모션 재작업과 체력바의 세부 연출을 진행한다. 옵션창과 보스 전용 착지 시안의 실제 연결도 남아 있다. [시스템 우선 과제의 당시 범위](2026-11-24-SYSTEMS-FIRST-BACKLOG.md)
