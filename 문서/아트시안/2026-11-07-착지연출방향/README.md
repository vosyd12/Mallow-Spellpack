# 착지 연출 방향 시안

작성일: 2026-11-07. 사용자 Notion의 학습·게임 참고 자료와 현재 프로젝트 화면을 바탕으로 만든 검토용 이미지다. 실제 게임 캡처·재생 프레임·구현 완료 자료가 아니다. Assets·코드·기획·마일스톤에는 적용하지 않았다.

## 사용자 요청과 해석

기존 번개의 균일한 선 형태와 다른 속성의 작고 짧은 효과로는 정상 플레이 중 충분한 보는 맛을 주지 못했다. 사용자는 과장과 시각적 완성도를 우선하며, 자신이 수집한 연출 자료를 참고한 이미지 시안을 요청했다.

Notion의 옥토패스 트래블러0 이미지에서는 픽셀 캐릭터와 선명한 발광·따뜻한 빛/차가운 빛의 대비·주변 바닥의 조명 반응을, Into the Dead의 공격 이미지에서는 충돌 지점의 섬광·파편·연기가 함께 보이는 구성을 참고했다. 학습 문서의 Impact Flash·Shockwave·Afterglow·Flipbook·Ribbon·Emission/Bloom을 현재 슬라임의 밝은 타일 화면에 맞춰 해석했다. 일부 학습 문서의 리듬 디펜스 규칙을 이 프로젝트의 규칙으로 옮긴 것은 아니다.

## 이미지

- [6속성 착지 비교](ELEMENT_LANDINGS.png): 속성별로 큰 주연 실루엣을 만들고 주변 입자·충격파·잔광을 조합한 피크 순간. 불의 화염 곡선, 물의 물보라, 땅의 돌·먼지, 바람의 리본, 번개의 전류, 무속성의 구름 같은 먼지로 구분한다.
- [번개 연출 4단계](LIGHTNING_TIMELINE.png): 착지 섬광 → 바닥 번개 확산 → 선택한 가지를 따라 달리는 빛 → 끊기며 남는 잔광. 0.00·0.12·0.28·0.65초 표시는 시안용 예시이며 확정된 수명 규칙이 아니다.

큰 형태·굵기 변화·밝은 중심과 유색 외곽·바닥에 번지는 색광을 우선해 기존의 얇은 선과 작은 입자를 개선하는 목표를 제시한다. 캐릭터 얼굴은 읽히도록 남겼다. 구현 가능 범위·실제 재생 타이밍·군집 화면의 가독성·모바일 비용은 이후 검토 대상이며 이미지 자체로 검증되지 않는다.
