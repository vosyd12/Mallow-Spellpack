# 현재 플레이어에 맞춘 슬라임 스타일 시안

작성일: 2026-11-10. 사용자 요청에 따라 기존 플레이어 v3와 품질·그림체를 맞춘 **이미지 검토용 시안**을 생성했다. 최종 외형 승인은 아직 받지 않았으며 코드·게임 Sprite·Prefab·Animation은 변경하지 않았다.

후속: 사용자가 이 스타일의 기존 이미지·파츠 교체를 요청해 [실제 적용과 Death 단독 클립](../../2026-11-10-SLIME-STYLE-V3-APPLIED.md)을 진행했다. 아래 미적용 설명은 최초 시안 작성 시점의 기록이다.

- [시안 PNG](SlimeStyleStudy_v1.png): 소·중·대 × 무속성·불·물·땅·바람·번개, 18종 비교표.
- 기준: [플레이어 v3 원화](../2026-11-10-플레이어마법사/PlayerMageConcept_v3.png)의 짙고 둥근 외곽선·넓은 명암·단순한 형태. 기존 플레이어/슬라임 아트 보드와 기존 대형 슬라임도 참조했다.
- 문제: 기존 슬라임의 픽셀 외형과 새 플레이어의 매끈한 외형 사이에 질감 차이가 있다. 같은 선·명암 기준으로 새 슬라임 외형을 제안해 비교한다. 실제 게임 통일감의 개선은 아직 확인하지 않았다.
- 생성 지시: 밝은 크림 배경에 6열·3행, 속성별 몸 색상, 크기 차이, 단순한 눈·입, 대형 콧수염을 표현한다. 눈썹·머리 위 속성 장식·픽셀 계단·과도한 광택은 제외한다.
- 확인: 18개 외형과 6속성·3크기 배치, 눈썹·머리 위 장식 부재, 대형 콧수염을 시안에서 확인했다. 내장 이미지 생성 도구를 사용했다.
- 남은 작업: 사용자 외형 검토, 필요 시 시안 보정. 투명 Sprite·파츠 분리·게임 적용·움직임 검증은 수행하지 않았다. 새 이미지가 그려졌다는 이유로 기존 슬라임이 교체됐다고 보지 않는다.
