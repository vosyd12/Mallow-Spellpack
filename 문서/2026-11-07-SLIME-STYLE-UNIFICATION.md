# 슬라임 이미지 스타일 통일

작업일: 2026-11-07. 사용자가 3종의 이미지 퀄리티 차이를 지적하고 같은 스타일로 교체를 요청했다.

## 문제와 원인

이전 얼굴 분리 작업에서 Small·Medium·Large 이미지를 각각 생성했다. 크기와 위치는 맞췄지만 외곽선, 픽셀 블록, 명암·하이라이트가 서로 달라 같은 게임의 개체라는 일관성이 약해졌다. 파일 해상도나 프리팹 크기를 맞추는 것만으로는 이미지 자체의 편차를 없앨 수 없었다.

## 선택한 해결 방법

빌트인 image_gen 도구로 공통 부품 아틀라스 하나를 만들고 3종이 실제로 같은 몸·눈 Sprite를 공유하도록 바꿨다. 개별 재생성은 다음 변경에서도 편차를 만들 수 있으므로, 공통 원본과 프리팹 색상으로 관리한다.

- 활성 이미지: `Assets/Sprites/Characters/SlimeStyleAtlas.png`.
- 구성: 위 왼쪽 회색 몸, 위 오른쪽 눈, 아래 왼쪽 미소, 아래 오른쪽 콧수염. 1254×1254 PNG를 627×627 셀 4개로 임포트한다.
- 몸은 회색 명암 베이스이며 Body의 SpriteRenderer Color로 색을 입힌다. 회색으로 생성된 것은 색상 공유를 위한 의도된 구성이다.
- Point 필터, Full Rect, 128 Pixels Per Unit, 일반 텍스처 압축을 사용한다.
- 세 종류의 기본 몸 비율은 Small 기준으로 맞췄다. 기존 개체별 몸 너비·바닥 기준과 부모 Visual 스케일은 유지했다. Medium의 높이는 공통 비율에 맞춰 소폭 조정됐다.

| 종류 | 공유 부품 | Body 색상 RGBA |
| --- | --- | --- |
| Small | 몸·눈·미소 | 0.78, 1, 0.84, 1 |
| Medium | 몸·눈·미소 | 0.36, 0.93, 0.68, 1 |
| Large | 몸·눈·콧수염 | 0.70, 0.98, 0.36, 1 |

색상은 프리팹의 `VisualRoot/Visual/Body`에서 바꾼다. 종류별 크기 차이는 기존 프리팹 스케일로 표현한다. 큰 개체는 확대되므로 화면상의 픽셀 크기까지 같다는 뜻은 아니다.

## 얼굴과 연출 연결

```text
VisualRoot/Visual
├─ Body                         공통 SlimeBody
└─ FaceMotion                   기존 지연 흔들림 경로 유지
   └─ Face
      ├─ Eyes                   공통 SlimeEyes
      └─ Smile 또는 Moustache   표정 부품
```

눈과 표정을 같은 도트 비율로 배치했다. 몸·그림자·HP바 Animation, 착지 파동과 먼지, 이동·피해·HP바 코드는 이번에 바꾸지 않았다. 원본 PNG와 이전 `SlimeSmallLayers.png`, `SlimeMediumLayers.png`, `SlimeLargeLayers.png`는 보존했지만 현재 슬라임 프리팹은 이전 Layers 이미지를 참조하지 않는다.

현재 SpriteRenderer는 몸·눈·입/콧수염·그림자의 4개다. 이전의 얼굴 한 장에서 눈·표정을 나누면서 개체당 Renderer가 하나 늘었다. 실제 드로 콜·메모리·성능 수치는 측정하지 않았다.

## 확인 결과와 남은 확인

생성 결과에서 네 부품의 분리와 공통 그림체를 확인했다. 파일 검사로 3종이 동일한 몸·눈의 GUID와 Sprite ID를 사용하는지, 4개 셀과 내부 참조가 유효한지, 기본 몸의 월드 가로세로 비율이 약 1.55728로 일치하는지 확인했다. 코드·Animation·씬·기존 효과 파일은 작업 전후 해시가 동일하다.

Unity 임포트·Play Mode·MCP·Notion·실기기 성능 검증은 하지 않았다. 실제 화면에서 색상·얼굴 간격·작은 크기의 가독성은 사용자가 확인해야 한다. 향후 공통 외곽선·명암 수정은 이 아틀라스 하나에 적용하고, 색상 변경에는 개별 이미지를 다시 생성하지 않는다.

생성 방식은 빌트인 image_gen이며 [최종 프롬프트](검증자료/2026-11-07-슬라임스타일/IMAGE_PROMPT.txt)를 보존했다. 중립 몸과 분리된 눈·미소·콧수염, 투명 배경, 공통 픽셀 윤곽과 하이라이트를 지정했다.
