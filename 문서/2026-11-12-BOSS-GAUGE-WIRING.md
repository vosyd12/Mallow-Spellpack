# 일반 몬스터 처치와 보스 진행도 연결

## 문제·원인·연결

사용자가 작성한 Enemy.Die → Stage.BossGauge → StageInfo.SetInfo 흐름은 준비됐지만 EnemySpawner의 Stage 참조가 저장되지 않아 진행도 전달이 생략되는 상태였다.

`Assets/Prefab/Stage.prefab`의 EnemySpawner._stageController에 같은 Prefab의 Stage 컴포넌트를 연결했다. SampleScene은 이 연결을 상속하며, 기존 StageInfo HUD 참조와 적 생성 시 Initialize(player, stage) 호출을 사용한다. 목표 처치 수는 현재 코드 기본값과 같은 30으로 저장했다.

## 달라진 점

- 일반 몬스터 사망 판정마다 처치 수 1 증가, 진행도는 처치 수 ÷ 목표 수다.
- 첫 스테이지는 1마리 약 3.33%, 15마리 50%, 30마리 100%이며 이후 추가 처치는 진행도를 늘리지 않는다.
- 기존 IsDead 검사로 중복 사망 집계를 막는다. 사망 클립이 끝나기 전 사망 판정 시점에 집계한다.
- 기존 HUD는 100%에서 보스 등장 안내 문구를 표시한다. 실제 보스 생성·스테이지 완료 호출·플레이어 사망 화면은 이번에 연결하지 않았다.
- C#·기존 사망 모션·페이드·표정은 수정하지 않았다. 다음 스테이지 목표 증가와 초기화는 사용자 코드에 준비된 동작이며 이번 작업의 실행 검증 결과가 아니다.

## 확인 결과·남은 확인

Prefab 내부 Stage 객체 ID, 씬의 Prefab 상속·StageInfo 참조와 기존 HUD 표시 필드, 사망 호출·게이지 계산 경로를 파일로 대조했다. MCP·Notion과 Unity 실행은 사용하지 않았다. 실제 게임에서 처치 직후 게이지 증가·30마리 이후 100% 유지·새 스테이지 진입 초기화 확인은 남았다.
