# 레벨업 카드와 화염 장판 작업 인수인계

## 화염 장판 · 문제 발견부터 해결까지

1. **문제 발견** — 수렴 중 갈래 끝의 불꽃 스프라이트가 함께 움직여, 불씨가 모여 새 불꽃에 점화되는 장면보다 이미 완성된 불꽃들이 이동하는 것처럼 보였다. 중앙 점화의 인상이 약해지고, 소멸 때 여러 요소가 비슷한 시점에 꺼졌다.
2. **원인 확인** — 8개 갈래마다 꼬리와 별도 Tip 스프라이트가 있었다. 기존 클립에서 중앙 불꽃은 약 0.47초부터 나타나고 갈래는 0.65초에 꺼져 두 구간이 겹쳤다. 테두리·바닥·중앙 불꽃에는 비슷한 시점에 시작하는 페이드가 들어 있었다.
3. **해결 방식과 이유** — 수렴 방향을 보여주는 꼬리와 불씨를 살리고 Tip의 알파를 0으로 고정했다. 각 갈래의 움직임에 최대 0.065초의 스태거를 주었다. 중앙에서는 스케일 오버슈트로 불꽃이 한 번 크게 솟았다가 안착하도록 했다. 얇은 빛 고리는 장판 지름까지 확장하면서 페이드아웃한다. 초반 테두리로 피해 범위를 보여주고, 소멸 구간에는 테두리부터 시차를 두고 옅어지게 했다.
4. **달라진 점** — 수렴·점화·잔불을 순서대로 읽히게 했다. 기존 얼굴 있는 중앙 플립북과 잔불을 활용했으며, 2초 클립과 피해·쿨다운 설정은 유지했다. 수정 위치는 Assets/Animations/Effects/FireAreaVortex.anim이다.
5. **확인 결과** — Unity 6000.5.10f1의 IngameScene Play Mode 자동 발동에서 0.23초에 Tip과 중앙 불꽃의 알파가 0, 0.70초에 중앙 불꽃과 확장 고리가 표시됨, 1.83초에 테두리가 중앙 불꽃보다 먼저 옅어짐을 확인했다. 프리팹 클립 샘플에서는 2초에 주요 요소가 모두 사라졌다. 점화 강도와 잔불 밀도에 대한 사용자의 전투 화면 확인을 기다린다. [상세 기록](2026-11-23-FIRE-AREA-VFX-REFINEMENT.md)

## 레벨업 카드 · 결정과 해결 과정

1. **문제 발견과 원인** — 시안에서 선택한 카드가 바스러져 선택 결과의 강조가 약해졌다. 씬에서는 CardPanel이 자신을 Card Root로 참조해 시작 시 이벤트를 받는 오브젝트까지 비활성화했다. 가로 화면 검증 중 카드 제목이 스테이지 HUD와 겹쳤다.
2. **해결 방식과 이유** — 기존 HUD의 크림색·올리브색·잎 장식을 적용했다. 세 장은 앞뒷면을 바꾸며 차례로 뒤집힌다. 선택 카드에는 확대와 UV 왜곡을 구운 후광을 사용해 시선을 모으고, 미선택 카드 두 장에는 하단부터 진행하는 방향성 디졸브와 낙하 파편을 적용했다. 선택 카드와 후광은 마지막에 함께 페이드아웃한다. 활성 부모 아래 CardRoot 자식만 켜고 끄도록 연결하고, 화면 비율에 맞춰 카드 묶음의 높이를 제한했다.
3. **구현 방식** — Unity Animator 키프레임과 보간으로 Tweening, Easing, Scale Tween, Scale Down, Fade Out을 구현했다. Highlight는 후광 플립북으로, 중복 선택 차단은 Closed → Opening → Choosing → Confirming의 UI State로 처리한다. LeveledUp → FinishOpening → 카드 클릭 → FinishConfirmation이 이벤트 기반 흐름을 이룬다. 에셋은 Assets/UI/LevelUpCards와 Assets/Animations/UI/LevelUpCards에 있고, 씬과 기존 LevelUpCardPanel.cs를 연결했다.
4. **확인 결과** — Unity 6000.5.10f1의 IngameScene Play Mode에서 세 카드 각각의 선택, 입력 잠금과 해제, 패널 재등장, 정상 게임 시간 진행을 확인했다. 1920×1080과 900×1600 Game View에서 배치와 클릭 영역을 확인했다. 버튼 가운데를 기준으로 레이캐스트를 검증했으며 모바일 실기기 성능은 확인 전이다. [상세 기록](2026-11-23-LEVEL-UP-CARD-PRESENTATION.md)

## 다음 작업 인수인계
