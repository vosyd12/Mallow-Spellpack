# 골드와 플레이어 스탯창

`IngameScene`의 별도 `StatsWindow`에 사용자가 작성한 `PlayerStatsPanel`을 붙였다. 보유 골드와 HP·MP 현재치 및 최대치, STR·DEX·CON·INT·WIS·LUK·AFF, 강화 비용과 `+`를 연결했다. `PlayerInfoPanel`은 기존 HUD를 맡는다. 플레이어의 실제 `StatUpgradeCost`와 `StatUpgradeIncrease`는 수치 결정 전이라 0으로 저장했다.

- `Assets/Animations/UI/StatsWindow`의 키프레임으로 창을 짧게 페이드인·확대하고 강화 버튼을 눌렀을 때 해당 값만 한 번 강조한다. 버튼은 `UpgradeRow` 호출 후 해당 값의 Animator에 신호를 보낸다.
- 각 `?`는 공통 툴팁에 항목의 효과를 표시한다. INT는 기본 마법 공격 피해, DEX는 현재 회피 이동 속도에 반영된다. 아직 실제 계산에 연결되지 않은 효과는 툴팁에 표시했다. 별도 정적 한글 SDF 에셋으로 스탯창 문구를 지원한다.

## 다음 작업 인수인계

- **결정** — **확정** 일반 적 처치 10골드, 왕관 보스 처치 100골드. 기본 UI에서 9개 강화 대상을 연결한다. **검토 중** 최종 강화 비용·상승량과 추가 전투 효과.
- **적용** — 스탯창과 버튼 참조, 열기·강화 키프레임, 공통 툴팁과 한글 폰트 에셋을 저장했다.
- **검증** — Unity 6000.5.10f1의 `IngameScene` 375×808 Game View에서 MCP 포인터 입력으로 화살표, 창 열기와 닫기, 9개 툴팁과 한글, 행별 강화와 골드 갱신을 확인했다. Play Mode에서만 12골드·+1로 설정하고 두 적을 처치해 110골드를 얻은 뒤 9회 강화해 2골드가 남는 것을 확인했다. 최대 HP·MP를 강화할 때 현재치 유지, 골드 부족 시 버튼 잠금, 재열기 후 값 유지와 툴팁 초기화도 확인했다. 콘솔 오류는 0건이었다.
- **다음 작업** — 실제 강화 비용·상승량을 결정하고 연결되지 않은 스탯의 전투 효과를 구현한다.
- **공유 기준** — 이전 인수인계의 원격 `main` 기준은 `259aba2`다. 원격 최신 상태는 미확인이다. 씬·연출 에셋·문서 변경은 현재 작업 폴더에 저장했다.
