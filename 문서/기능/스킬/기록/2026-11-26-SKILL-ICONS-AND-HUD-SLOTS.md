# 스킬 카드 아이콘과 HUD 슬롯

2026-11-26. Unity `6000.5.10f1`의 `Assets/Scenes/IngameScene.unity`에서 사용자가 요청한 아이콘 6종 교체와 슬롯 3~5의 중복 표시 수정을 적용했다. C#은 사용자가 담당하고, 이번 변경은 아이콘 에셋과 씬의 직렬화 설정으로 적용했다.

## 적용 범위

- 카드와 HUD가 이미 공유하는 `SkillData._iconSprite`에 `Assets/UI/SkillIcons/`의 전용 스프라이트 6종을 연결했다. 기존 전투 연출에 쓰이는 이미지와 카드 배경을 그대로 사용한다. Unity에서 투명 단일 Sprite로 가져오고 최대 크기를 256으로 설정했다.
- 기존 HUD 슬롯 인덱스가 `0, 1, 1, 1, 1`이라 슬롯 3~5가 두 번째로 획득한 스킬을 표시했다. `0, 1, 2, 3, 4`로 수정했다.
- 첫 카드에서 아이콘·배경 원·이름이 위로 올라간 것을 Game View에서 확인하고 나머지 두 카드와 같은 위치에 맞췄다.

## 이미지 제작 기준

내장 ImageGen으로 아이콘을 한 장씩 생성했다. 공통 프롬프트는 투명한 정사각형에 둥근 스티커 형태, 자주빛 굵은 외곽선, 단순한 채색과 밝은 하이라이트를 적용하고, 작은 HUD 크기에서 알아볼 수 있게 여백과 실루엣을 맞추는 것이었다.

| 에셋 | 개별 프롬프트의 소재 |
| --- | --- |
| `WaterBall.png` | 물방울과 짧은 분사 꼬리 |
| `FireArea.png` | 타원형 바닥 고리 위의 둥근 불꽃 |
| `LightningChain.png` | 세 개의 빛점 사이를 연쇄하는 번개 |
| `WindPulse.png` | 밖으로 퍼지는 민트색 곡선 돌풍 |
| `EarthShield.png` | 튕겨내는 빛이 있는 둥근 돌 방패 |
| `PureTrail.png` | 끝에 작은 폭발이 있는 보라색 발자국 |

## 확인 결과

- Unity MCP Play Mode에서 경험치를 주입하고 카드의 실제 버튼 이벤트로 6종을 차례로 선택했다. 카드의 스프라이트와 후보가 일치했고, 선택 중 시간 정지와 확정 뒤 재개를 확인했다. 처음 획득한 5종은 획득 순서대로 각 HUD 슬롯에 표시됐다. 획득 순서를 바꿔 6종 모두 카드와 HUD에 표시되는 것을 확인했다. 540×829 Game View 캡처에서 카드와 HUD를 확인했고, 정렬 수정 후 카드 세 장의 아이콘 높이도 다시 확인했다.
- 연속 획득 시험에서는 여섯 번째가 HUD에 표시되지 않았다. 이후 사용자가 실제 플레이의 5슬롯 구성이 정상임을 확인했다.
- 수정 전 카드의 `획득`·`강화` 줄은 텍스트 영역에서 잘렸다. Play Mode에서 영역을 임시로 늘리자 해당 한글 글리프가 네모로 표시됐다.

## 카드 문구 후속 수정

- 사용자 요청에 따라 `IngameScene`의 카드 텍스트 영역을 높이 48에서 80으로 늘리고, 기존 `TopHUDKoreanSDF.asset`에 `획·득·강·화`를 같은 글꼴로 추가했다. 정적 아틀라스와 기존 문자 86개를 보존했다.
- Unity MCP Play Mode의 540×829 Game View에서 신규 카드의 `획득 · Lv. 1`과 기존 스킬 카드의 `강화 · Lv. 2`가 두 번째 줄에 잘림과 대체 문자 없이 표시되는 것을 확인했다. Play Mode를 종료하고 씬·폰트 저장과 글리프 목록을 확인했다. 실기기 검증은 수행하지 않았다.
