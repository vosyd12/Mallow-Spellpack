# 속성 스킬 이펙트 개선

후속 [인게임 재생 연결과 검증](2026-11-26-ELEMENTAL-VFX-RUNTIME.md)에서 이 프리팹들을 실제 스킬 판정에 연결했다.

2026-11-26. 사용자가 지정한 번개 연쇄·바람 돌풍·땅 보호막·무속성 이동 흔적의 이펙트를 Unity `6000.5.10f1` 에디터에서 다듬었다. 워터볼과 화염 장판은 사용자 지정 범위에서 제외했다. Unity MCP로 `Assets/Prefab/Effects/ElementalSkills/`의 기존 프리팹 7개와 애니메이션 클립 9개를 편집했다. 게임 C# 연결은 사용자가 담당한다.

| 스킬 | 적용한 연출 |
| --- | --- |
| 번개 연쇄 | 황금색 지그재그의 중심광과 짧은 가지, 타격점의 작은 빛 알갱이와 확산 고리를 적용했다. 연결선의 로컬 +X 기준을 유지했다. |
| 바람 돌풍 | 민트색 곡선 세 개를 안쪽에서 바깥으로 펼치고 작은 파티클을 같은 방향으로 퍼뜨렸다. 기본 범위 표시는 반경 2유닛 기준을 사용한다. |
| 땅 보호막 | 금빛 가장자리의 둥근 방패로 외곽을 교체했다. 등장, 유지, 만료 클립의 실루엣을 맞추고 방어 시에는 일부 곡선과 돌 파편이 흩어지게 했다. |
| 무속성 이동 흔적 | 원형 문양을 보라색 발자국 두 개로 바꾸고, 접촉 폭발 프리팹에는 별 모양 섬광과 확산 링을 적용했다. |

기존 프리뷰에서 일부 효과의 큰 흰색 형태가 중심을 가렸다. 발광선, 부드러운 잔상, 둥근 파티클용 URP 머터리얼을 효과 전용으로 구성하고 타격점의 파티클을 작게 조정했다. 발광부는 기존 씬 Bloom 설정을 사용하도록 머터리얼에서 밝기를 구성했다. 화면 전체 설정은 변경하지 않았다.

## 확인 결과

- Unity Edit Mode에서 같은 밝은 초원색 배경에 기존·수정 프리팹을 샘플링했다. 연결선과 발자국의 대비, 보호막의 유지·만료, 효과별 종료 시 마지막 키프레임을 확인했다. 기존 클립 길이, 컨트롤러와 `PureTrailMark`의 씬 참조를 보존했고, 검사 도중 열린 `IngameScene`의 저장본과 스냅샷이 일치했다. [에디터 프리뷰 이미지](../../../검증자료/2026-11-26-ElementalVfx-Editor-Preview.png)
- 이동 흔적 본체는 기존 `_markPrefab` 연결을 사용한다. 번개 연쇄, 돌풍, 보호막, 흔적 접촉 폭발의 판정 시점 연출 재생은 [정리된 연결 지점](../../../2026-11-25-ELEMENTAL-SKILLS-HANDOFF.md#2026-11-26-연출-프리팹과-play-mode-검증)을 따른다. 실제 전투의 통합 Play Mode와 실기기 검증은 수행하지 않았다.
