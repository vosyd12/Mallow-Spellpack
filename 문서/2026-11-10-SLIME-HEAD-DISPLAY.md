# 슬라임 머리 위 속성 표시 제거

작성일: 2026-11-10. 사용자 요청에 따라 MCP 없이 로컬 Prefab 파일의 외형 표시만 변경했다.

## 문제와 선택한 방법

불꽃·물결·돌·소용돌이·번개가 머리 위에 따로 표시된다. 원본 확인 결과 몸·얼굴·머리 장식은 이미 분리돼 있었다. PNG를 재생성하면 몸의 윤곽·명암·픽셀 위치가 달라질 수 있으므로, 기존 이미지 품질을 유지하는 방법으로 분리된 장식 계층만 비활성화했다. 이미지 생성 도구는 사용하지 않았다.

## 변경

- `Assets/Prefab/SlimeSmall.prefab`, `SlimeMedium.prefab`, `SlimeLarge.prefab`의 `ElementAnchor` GameObject를 비활성화했다.
- 자식 `ElementMotion/ElementVisual`의 머리 장식이 함께 표시되지 않는다. 계층과 Sprite 참조는 보존해 기존 Animation 바인딩을 끊지 않았다.
- 속성 Variant 18종은 기본 Prefab의 설정을 상속한다. 무속성도 같은 설정을 받으며 원래 없던 장식을 추가하지 않는다.
- 몸·얼굴·수염·그림자·HP바·피격 Material과 속성 분류 데이터는 변경하지 않았다. 착지 입자·속성 바닥 연출도 이번 범위에서 제거하지 않았다.

## 확인 결과와 한계

- 기본 3개 파일은 해당 활성 값 `1→0` 외 내용이 동일함을 비교했다.
- Variant 18종의 기본 Prefab 연결과 해당 활성 값의 개별 override 부재를 확인했다.
- 캐릭터 PNG·슬라임 Animation의 작업 전후 해시 변경은 0개다. 이미지 픽셀을 바꾸지 않아 기존 몸과 얼굴의 품질을 그대로 보존한다. 해당 계층을 다시 켜는 Animation 활성 곡선도 없음을 파일로 확인했다.
- 본 작업은 C#을 편집하지 않았다. 검사 중 HitReaction.cs에 외부 변경 1개가 감지돼 그대로 보존했으며, 전체 C# 해시가 동일하다고 보고하지 않는다.
- MCP 연결·실행 검증은 사용자 지시에 따라 하지 않았다. 재생 중 이미 생성된 개체는 기존 상태일 수 있으므로, 저장된 변경을 확인할 때는 재생을 다시 시작해야 한다.

기존 수정 요청 8개 중 머리 위 별도 속성 표시 제거만 반영했다. 다른 표정·사망·착지·성능 과제는 완료 처리하지 않는다.
