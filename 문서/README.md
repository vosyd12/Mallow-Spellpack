# 프로젝트 현황과 문서 안내

갱신일: 2026-11-09. [현재 작업 요약·후속 과제](2026-11-09-WORK-SUMMARY.md)에서 적용한 배경·슬라임·HUD와 시안·미적용 개선안을 구분해 확인한다. 잘못 적용했던 연출 변경은 원복했고, 승인한 가림·겹침 개선과 StageScenery 연결은 유지한다. 아래 과거 기록의 실행 결과는 각각의 시점에 한정하며 전체를 다시 검증한 결과가 아니다.

## 새 수정사항·문제점·개선점

[캐릭터·전투·성장·진행 연출 수정 과제](2026-11-09-PLAYER-COMBAT-EFFECTS-TODO.md)에 플레이어 이미지 교체·애니메이션 우선 방향, 기본 공격·레벨업 버튼·완료 반응, 사망 화면, 보스·스테이지 전환 연출을 추가했다. 이어 추가 후보 5개를 수정 요청으로 등록하고 HitStop·슬라임 피격 표정·평상시 눈 깜빡임도 포함했다. 모두 미구현이며 사망·표정은 기존 과제와 통합했다. 구체적인 표현·적용 조건·수치는 미정이다.

[UI·연출 통일과 기본 재미 개선 검토](2026-11-09-UI-AND-GAME-FEEL-REVIEW.md)에 폰트·이미지 품질 편차, HUD 개성·시선 구성·등장 연출, 기존 전투·성장 반응과 관찰하는 재미에 대한 제안을 정리했다. 문서화만 진행했으며 세부 스타일·전투 규칙과 실제 개선 효과는 미확정이다. 현재 레벨업은 스탯을 올리지 않고, 속성 외형과 속성 전투 효과도 구분한다. 최신 HUD 배치는 [적용·축소 기록](2026-11-09-HUD-STYLE.md)을 따른다.

## 현재 상태

현재 착지는 2026-11-08의 속성별 파티클·프레임 애니메이션 구성이다. 앞서 수정했던 아틀라스 표시 오류·바람 회전 경고와 반짝임·절차적 번개 방식은 [이전 셰이더 기록](2026-11-07-ELEMENT-LANDING-SHADER-FIX.md)에 남겼다. 현재 표시와 풀 반환·재사용 확인 범위는 [착지 애니메이션 기록](2026-11-08-ELEMENT-LANDING-ANIMATION.md)을 따른다.

배경은 잔디 Tilemap과 4타입 Prefab 8종으로 구성하고, 후보 지점에서 타입별 3~4개를 배치한다. 플레이어·슬라임·장식에 공통 그림자 기준을 적용했으며, 11월 8일 배경 작업에서는 적 5개체의 생성·이동과 오류·경고 0개를 확인했다. [당시 적용·검증 범위](2026-11-08-SCENERY-PREFABS-SHADOWS.md). 독립 수량 필드와 단계별 함수 분리는 이후 사용자 코드에 반영됐으며, [현재 연결 기록](2026-11-09-STAGE-SCENERY-RECONNECT.md)을 따른다.

전체 맵 관찰에서 확인한 식별 문제에 대응해 Small 외형을 변경 직전의 1.6배, Medium·Large·플레이어를 1.5배 확대했다. 몸·얼굴·속성 장식을 분리하고 장식의 형태를 유지하며, 속성별 착지 효과 6종을 씬의 풀에 연결했다. 별도 Unity 복사본에서 관련 Prefab 27개의 정상 임포트를 확인했으며 변경 후 Play Mode의 가독성·재생은 사용자 확인이 남았다. [최신 적용·연결 위치](2026-11-07-SLIME-READABILITY-SETUP.md) · [변경 전 관찰](2026-11-07-SLIME-ELEMENT-READABILITY.md) · [새 아틀라스](검증자료/2026-11-07-슬라임가독성개선/PREVIEW.html).

속성 Prefab을 슬롯에 넣을 수 없던 문제는 내부 오브젝트에 예약 ID `100100000`을 사용한 것이 원인이었다. 18종의 ID·연결 참조를 수정하고 Spawner 목록도 복원했다. 기존 파일 검사는 이 오류를 놓쳤으며, 이번에는 별도 Unity 6000.5.10f1 프로젝트에서 18종의 정상 임포트와 종료를 확인했다. 실제 전투 재생 검증과 구분한다. [원인·수정·재발 방지](2026-11-07-PREFAB-RESERVED-ID-FIX.md).

플레이어·기본 슬라임 3종에 HitReaction과 공통 HP바의 노란 DamageFill을 연결했으며 속성 Variant 18종도 상속한다. 사용자 코드의 대기 조건·피격 호출 수정을 확인했고 AI는 C#을 수정하지 않았다. 연속 피격의 피해 차이는 유지되지만 매 피격마다 대기 시간이 갱신된다. HP 0의 빠른 잔상 정리는 미구현이며 적은 현재 즉시 삭제된다. [연결·한계·조절 위치](2026-11-07-HIT-REACTION-HP-TRAIL.md).

`SampleScene`의 Spawner는 속성 Variant 18종을 등록한 상태다. 각 Prefab의 `EnemyState.Size`·`Element`로 사용자 코드가 추첨한 개체를 찾는다. 현재 5속성의 몸·장식은 `Slime{속성}IndependentLayers.png`, 얼굴과 무속성 몸은 기존 `Slime{속성}{크기}Layers.png`를 사용한다. 공통 피격·HP 잔상 연결은 유지했다. 속성별 착지 외형은 연결됐으며 추가 전투 효과는 미구현이다. [생성 연결](2026-11-07-ELEMENTAL-SLIME-SPAWN.md) · [최신 외형 구조](2026-11-07-SLIME-READABILITY-SETUP.md).

타깃 검색과 자동 공격 연결, 가장자리 적 생성, 처치 경험치 지급이 작성됐다. 슬라임은 한 파일의 작은 상태 관리로 일반/공격 도약과 먼지를 재생한다. 사용자 코드에 HP 갱신과 공격 착지의 피해 호출이 연결됐으며, 기존 로그에서 플레이어 HP 감소를 확인했다. 줄지 않던 HP바는 Sliced 설정이 원인이어서 공통·슬라임별 Fill을 Filled로 수정했다. 수정 후 실제 화면의 감소 표시는 사용자가 확인해야 한다.

## 우선 확인할 미완료 항목

1. HP바 비율 전달·Filled 설정은 연결됐다. 실제 플레이 화면에서 감소 표시와 가독성을 확인해야 한다.
2. 플레이어 최대 HP는 100, 최대 MP는 씬에서 50으로 설정돼 있다. HP 0 이후의 사망 흐름과 잔상 빠른 정리는 남았다.
3. TryHitPlayer의 공격 착지 호출은 연결됐다. 회피로 범위를 벗어나면 피해가 발생하지 않는 조건까지 실제 플레이에서 확인해야 한다.
4. 생성 설정은 4, 조건은 Count > 제한값이라 5마리까지 생성 가능하다. 우선 1마리 유지 규칙과 차이가 있다. 재시도 시간도 현재 시각에서 0.5초를 빼고 있어 대기가 적용되지 않는다.
5. 회피 여유 거리 코드와 기존 안전거리 반환이 겹친다. 게임오버·재시작·화면 비율 자동 대응은 없다.

타깃 검색 타이머·Spawner 슬롯·Player.Target과 Bullet의 Enemy 대상 연결은 현재 해결된 상태다. 과거 문서의 같은 미완료 항목보다 이 문서와 최신 정리를 우선한다. 코드 수정은 사용자가 주도한다.
