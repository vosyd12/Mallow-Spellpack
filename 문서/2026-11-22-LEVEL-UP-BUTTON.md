# 레벨업 버튼 클릭 반응

기존 `LevelUpButton`은 색 변화로 입력 상태를 표현했다. 클릭 시 입력이 전달됐다는 느낌을 살리기 위해 버튼 배경과 글자가 함께 작아졌다가 돌아오는 동작을 추가했다.

- **확정** — 작업 범위는 `IngameScene`의 버튼 클릭 반응이다. 기존 `Player.TryLevelUp()`, 클릭 가능 조건과 버튼 색을 그대로 사용한다.
- **적용** — `LevelUpButton/ButtonVisual`에 원래 배경과 `Label`을 배치했다. 기존 버튼 크기의 투명 Image가 입력을 받는다. 버튼을 클릭하면 Animator의 `Press` 트리거가 표시 부분을 0.05초에 94%로 줄이고, 0.15초까지 100%로 복원한다. 연속 클릭은 클립을 다시 시작한다.
- **검토 중** — 레벨업 가능 전환에 테두리 알림을 추가하는 작업과 성공 시 빛 기둥·`LEVEL UP!` 연출은 후속 범위다. `Player.LeveledUp` 및 `PlayerLevelUpEffect` 코드가 있으며, 연출 에셋 제작과 씬 참조 연결이 남았다.
- **파일 검증** — 씬의 오브젝트 참조, 버튼 이벤트 2개, 기존 색 설정과 문구, 클립의 크기 키와 상태 전환을 대조했다.
- **실행 검증** — 별도 Unity 6000.5.10f1 프로젝트의 `IngameScene` Play Mode에서 자동 입력으로 확인했다. 비활성 상태에서는 레벨과 크기가 그대로였고, 경험치 210에서 클릭 두 번으로 레벨 1→2→3과 경험치 210→110→0을 확인했다. 두 클릭 모두 표시 크기가 94%에 도달했고 마지막 클릭 후 원래 크기로 돌아왔다. 축소 중에도 원래 버튼 오른쪽 가장자리에서 입력을 감지했다.

조절 위치는 `Assets/Animations/UI/LevelUpButtonPress.anim`의 크기 키와 `LevelUpButton.controller`의 `Press` 상태다.

- **적용** — 배경과 글자의 축소·복원 클립을 버튼 클릭에 연결했다.
- **검증** — 파일 참조와 Play Mode의 연속 클릭·입력 영역·크기 복원을 확인했다.
- **다음 작업** — 버튼 피드백의 강도를 실화면에서 확인한다. 이후 버튼 사용 가능 알림과 성공 시 빛 기둥·머리 위 문구의 제작 범위를 정한다.
- **공유 기준** — 로컬에서 확인한 `origin/main`은 `4eb993e`다. 버튼 씬 변경과 애니메이션, 문서는 작업 폴더에 있다.
