# 타이틀 화면 기본 배치

2026-11-26. 타이틀 작업을 먼저 진행하기로 했다. 기존 `Assets/Scenes/TitleScene.unity`에는 카메라만 있어, Unity 에디터에서 화면 구도를 확인할 수 있도록 임시 제목과 버튼 위치를 잡았다.

## 배치

- `TitleCanvas`는 Screen Space Overlay이며 Canvas Scaler의 기준 해상도는 1080×1920이다. 화면 높이를 기준으로 배율을 맞춘다.
- `Background`는 전체 화면을 채우는 단색 UI Image다. 화면 위쪽 중앙에 `GameTitle`을 두고 기본 TextMeshPro 글꼴로 `Mallow Spellpack`을 표시한다. 제목 영역은 가로 폭에 맞춰 늘어나고 좁은 화면에서는 글자 크기를 줄인다.
- 화면 중앙 아래의 `MenuButtons`에 같은 폭의 `PLAY`와 `SETTINGS` 버튼을 세로로 배치했다. 배경과 버튼의 Sprite 슬롯은 비어 있다. 두 버튼의 `On Click`은 동작을 연결할 자리로 남겨 뒀다.

## 확인

Unity 6000.5.10f1의 Play Mode에서 590×865 Game View에 제목·버튼 두 개가 잘리지 않고 표시되는 것을 확인했다. 콘솔 오류와 경고는 0건이었다. Play Mode를 종료하고 씬을 저장한 상태로 열어 뒀다.
