# 쿼터뷰 카메라 설정

현재 상태: 아래 쿼터뷰 설정은 사용자 피드백으로 취소했다. 현행 설정은 하단 원상복구 항목을 따른다.

- 요청: MCP로 쿼터뷰만 빠르게 적용.
- 변경: SampleScene의 SceneSetup/Main Camera 위치를 (8, 8, -12)로 설정하고, 원점인 Stage 중심을 바라보도록 회전했다. 바라보기의 위쪽 기준은 월드 Z축이다.
- 투영: Orthographic 유지, Size는 5에서 7.5로 변경해 현재 Game 뷰에서 바닥 전체가 들어오도록 했다.
- 확인: 카메라 캡처에서 타일 바닥이 대각선 쿼터뷰로 표시되는 것을 확인하고 씬을 저장했다. Play 모드 실행은 하지 않았다.
- 범위: 카메라 설정만 변경했다. Stage·캐릭터의 XY 배치와 C# 코드는 유지했다. 스프라이트도 함께 기울어져 보이며, 캐릭터를 세워 보이는 외형 처리와 화면 비율 자동 대응은 포함하지 않았다.

## 원상복구

- 사용자 의도는 기존 정면에서 아래로 살짝 기울이는 느낌이며, 대각선 바닥 구도는 원하지 않았다.
- 요청에 따라 카메라 위치 (0, 0, -10), 회전 (0, 0, 0), Orthographic Size 5로 복원하고 씬을 저장했다.
- 약한 기울기는 이번 복원에 추가하지 않았다.
