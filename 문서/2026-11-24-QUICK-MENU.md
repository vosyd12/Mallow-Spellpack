# 우측 상단 메뉴 버튼

`Assets/Scenes/IngameScene.unity`의 기존 `HUDCanvas`에 `QuickMenu`와 `StatsWindow`를 배치했다. 아래쪽 화살표를 누르면 스탯·스킬 트리·옵션 버튼이 나타나고, 위쪽 화살표를 누르면 접힌다. 스탯 버튼을 누르면 메뉴가 접히며 기본 스탯창이 열리고, 닫기 버튼으로 돌아온다. 각 동작은 기존 Unity UI Button의 `On Click`에 `GameObject.SetActive`를 연결했다.

Unity 로그에서 정적 `Assets/UI/TopHUD/TopHUDKoreanSDF.asset`에 `리·션·옵·킬·탯·트`가 없어 네모로 대체되는 현상을 확인했다. 같은 글꼴의 누락 글자 6개를 기존 아틀라스의 빈 공간에 추가했다. 원본 글자 80개와 기존 폰트 참조를 보존했고, 수정된 아틀라스에서 `스탯`, `스킬 트리`, `옵션`을 렌더링해 글자 모양과 등록 여부를 확인했다.

## 다음 작업 인수인계

- **결정** — **확정** 버튼과 기본 열기·닫기를 먼저 적용한다. **보류** 실제 스탯 데이터, 스킬 트리·옵션 화면 연결.
- **적용** — `QuickMenu`와 제목·닫기 버튼만 있는 `StatsWindow`를 추가했다. 스킬 트리와 옵션은 비활성이다. 기존 HUD 폰트에 메뉴용 글자 6개를 추가했다.
- **검증** — 버튼 6개의 이벤트 대상과 값, 초기 표시 상태, 씬 파일 ID를 대조했다. 로그에서 씬 변경의 임포트와 수정 전 한글 누락을 확인했다. 수정 후 폰트 데이터와 아틀라스 렌더링을 확인했고, 새 폰트의 Unity 임포트와 Play Mode 입력·배치는 확인 대기다.
- **다음 작업** — 스탯·메뉴 표시를 Play Mode에서 확인하고, 스탯 작업 범위가 정해지면 실제 데이터를 연결한다.
- **공유 기준** — 이전 인수인계에 기록된 원격 `main` 기준은 `259aba2`다. 원격 최신 상태는 미확인이다. 씬 및 문서 변경은 현재 작업 폴더에 저장했다.
