# 하단 빈 스킬 버튼 5개

2026-11-17. Unity MCP로 현재 SkillBar의 빈 공간에 버튼 5개를 배치했다. 기존 미저장 씬은 `.utmp/SkillSlots-20261117/SampleScene.before.unity`에 복사했다. 게임 C# 파일을 추가·수정하지 않았고 스킬 발동이나 자동/수동 전환은 구현하지 않았다.

## 변경·원인·선택

SkillBar가 비어 있고 SkillSlotUI·PlayerSkill·FireballSkill은 아직 빈 클래스여서 UI 기반부터 구성했다. 단일 `Assets/Prefab/UI/SkillSlot.prefab`을 만들어 씬의 SkillSlot01~05가 같은 Prefab을 사용하게 했다. 슬롯마다 별도 에셋이나 매 프레임 실행되는 빈 스크립트를 추가하지 않았다.

SkillBar는 좌우 4% 안쪽·하단 6% 기준에 놓고, 중앙 Slots의 GridLayoutGroup에 132×132 셀 5개와 간격 16을 설정했다. 기준 행 너비는 724다. 현재 HUD Canvas의 균일 배율을 사용해 정사각형을 유지한다. 상단 HUD의 사용자 수정 상태와 World·Stage·플레이어 참조는 유지했다.

각 슬롯은 Image·Button과 눌림/비활성 색을 가진다. 빈 상태에는 `+`를 표시하고, Icon·CooldownOverlay(원형 Filled Image)·ModeLabel은 비활성 연결 자리로 준비했다. Button의 OnClick은 비어 있다. 아이콘 장착·쿨다운 갱신·선택 상태·자동 전환을 실제로 수행하는 코드는 없다.

초기 빈 상태 문구는 문자열 전달 문제와 현재 TopHUDKoreanSDF의 미포함 글자 경고가 있어 제거했다. 불필요한 폰트 재생성 대신 `+`만 쓰도록 단순화했으며 기존 폰트 에셋은 동일하다. 이후 자동/수동 등의 한국어 표시를 연결할 때 필요한 글리프 포함 여부를 확인해야 한다.

## 실제 확인

- 320×720·1080×2400·1536×2048에서 실제 Play·렌더를 확인했다. 슬롯 5개가 화면 안에 있고 정사각형을 유지한다. 각 크기는 약 44·147.58·162.58px다. 같은 픽셀 수나 물리적 크기를 보장한다는 뜻은 아니다.
- GraphicRaycaster로 각 중심점이 해당 슬롯 Button 배경에 도달하는지 확인했다. 5개 모두 Interactable이며 클릭 이벤트 연결은 0개다. 실제 스킬 사용을 검사한 것은 아니다.
- 기존 Assets 파일 506개는 동일 해시다(씬 제외). 상단 주요 RectTransform·씬 사용자 C# 컴포넌트·Stage/PlayerVisual 인스턴스와 참조는 작업 전과 같다. 새 게임 에셋은 SkillSlot Prefab과 메타 2개다.
- 원래 Game View 복원·임시 해상도 제거·Play 종료·씬 저장·Missing Script 0개를 확인했다. 슬롯 자체의 기기별 자동 Safe Area 코드는 없으며 하단 6% 여백만 사용한다.

## 후속 결정

수동/자동 전환을 슬롯별로 둘지 전체로 둘지, 모드 전환 조작과 발동 탭을 어떻게 구분할지, 수동 조준/자동 표적 및 물 Ball·불 장판의 생성 위치를 정해야 한다. 이후 쿨다운·발동 가능 조건·빈 칸 선택 동작과 실제 장착 데이터를 사용자 코드에 연결한다. UI 터치가 동시에 캐릭터 이동/전투 입력으로 처리되지 않도록 기존 입력 처리도 확인해야 한다. 위 사항은 제안·미정 범위이며 이번 UI 작업으로 확정하거나 구현하지 않았다.
