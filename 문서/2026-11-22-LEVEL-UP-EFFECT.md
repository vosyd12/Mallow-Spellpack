# 레벨업 성공 연출

이 문서는 빛 기둥과 `LevelUP` 문구를 적용했을 당시의 기록이다. 현재 씬의 상태는 후속 롤백 기록을 따른다. [롤백 후 상태](2026-11-22-LEVEL-UP-EFFECT-ROLLBACK.md)

- **확정** — 레벨업 성공 시 발밑에서 금빛이 바깥으로 퍼지고, 이어서 밝은 부분이 기둥을 따라 머리까지 솟는다. 머리 위 `LevelUP` 문구는 한 번 튕긴 뒤 읽을 시간을 두고 사라진다.
- **보류** — 레벨업 버튼의 사용 가능 알림과 카드의 등장·보상 규칙은 후속 작업이다.

## 구성

- `Assets/Prefab/Effects/LevelUpEffect.prefab`을 `IngameScene`의 `Player` 아래에 배치했다. 기존 바닥 그림자의 높이를 기준으로 위치를 잡고, 플레이어의 비균일 스케일을 보정했다.
- `Assets/Animations/Effects/LevelUpEffect.anim`에서 바닥 빛을 타원형으로 넓히고, 기둥의 Y축 스케일과 밝은 그라데이션의 Y축 위치를 각각 애니메이션으로 제어한다. 2D 스프라이트용 머티리얼은 키프레임 알파를 반영한다. 바닥과 움직이는 밝은 부분에는 HDR 색을 주어 기존 씬의 URP Bloom을 사용한다.
- 월드 공간 TMP의 크기는 66%에서 시작해 0.38초에 116%, 0.47초에 94%, 0.55초에 100%가 된다. 문구는 0.66초부터 옅어져 0.85초에 사라진다. 빛은 약 0.6초에 꺼진다.
- `PlayerLevelUpEffect`의 기존 Animator 슬롯을 `Base Layer.LevelUp`에 맞춰 연결했다. Particle System 슬롯은 짧게 떠오르는 작은 빛 입자 네 개를 재생한다.

## 확인 결과

- 씬의 새 프리팹과 기존 `PlayerLevelUpEffect`의 파티클·Animator 참조를 확인했다. 플레이어 외형과 블룸 프로파일은 기존 파일을 사용한다.
- Unity 6000.5.10f1의 복제된 `IngameScene` Play Mode에서 실제 버튼 경로로 두 번 레벨업했다. 첫 재생의 발밑 확산과 위로 움직이는 빛, 문구 반동과 체력바 간격, 연속 레벨업 시 처음부터 재생, 캐릭터 추적과 소멸을 확인했다.
- 같은 프레임을 HDR로 렌더링해 기존 Bloom의 켜기·끄기 출력을 비교했다. 대기 중과 빛의 소멸 후에는 빛 영역에서 출력 차이가 없는 것을 확인했다. 복제 에디터의 시작 과정에 Unity Search 인덱싱 예외가 있었으며, 연출 재생 검사는 통과했다.

## 다음 작업 인수인계

- **결정** — 발밑 확산과 상승하는 금빛, 한 번 튕기는 `LevelUP` 문구를 적용했다.
- **적용** — 전용 프리팹·클립·머티리얼을 만들고 기존 성공 이벤트 수신 컴포넌트에 연결했다.
- **검증** — 씬 참조, 연속 버튼 입력, 체력바 위 문구, 발광과 소멸을 확인했다.
- **다음 작업** — 버튼 사용 가능 알림과 레벨업 카드의 등장·보상 규칙을 정한다.
- **공유 기준** — 로컬에서 확인한 `origin/main`은 `4eb993e`다. 레벨업 성공 연출의 에셋·씬·문서 변경은 작업 폴더에 있다.
