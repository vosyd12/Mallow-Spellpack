# Stage 1.5배 확대

- 요청: 현재 Stage 가로·세로를 1.5배 늘리고 카메라 범위도 함께 조정.
- 변경: `Assets/Prefab/Stage.prefab` 루트 Scale을 (1, 1, 1)에서 (1.5, 1.5, 1)로 변경했다. 타일·배경·테두리·Bounds가 함께 확대된다.
- 실제 크기: 타일 바닥 6×7.5 → 9×11.25. 배경 포함 6.4×7.9 → 9.6×11.85. 원점 배치 기준 벽 내부는 월드 X=±4.5, Y=±5.625다. 이전 경계 기록의 좌표는 Prefab 로컬값으로 유지된다.
- 카메라: SampleScene Main Camera의 Orthographic Size 5 → 7.5. 위치와 회전은 그대로 유지한다. 같은 화면 비율에서 Stage의 화면 점유율은 유지되고 캐릭터·적의 화면 크기는 이전의 약 2/3이 된다.
- 캐릭터·적: Stage 외부에 있는 기존 배치를 유지해 실제 크기·이동속도·공격 거리는 변경하지 않았다. C# 코드 변경은 없다.
- 확인: Prefab 루트와 씬의 카메라 값, Stage 인스턴스에 별도 Scale override가 없음을 정적으로 확인했다. MCP 연결·Play 검증은 하지 않았다. 모든 모바일 화면 비율에 대한 자동 대응은 이번 범위가 아니다.
