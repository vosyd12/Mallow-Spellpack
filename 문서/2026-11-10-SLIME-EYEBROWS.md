# 슬라임 눈썹 표시 제거

작성일: 2026-11-10. 모든 슬라임을 눈썹 없는 얼굴로 맞추라는 요청에 따라 중형 6속성의 얼굴 Sprite 표시 범위를 조정했다. MCP·C# 수정·이미지 재생성은 하지 않았다.

## 원인과 선택한 방법

중형의 한쪽 눈썹은 얼굴 PNG 안에 눈·입과 함께 들어 있다. 소형은 눈썹이 없고 대형은 눈과 콧수염으로 구성된다. 눈썹은 눈·입보다 위에 분리돼 있으므로 얼굴 Sprite의 위쪽 범위만 제외하는 방법을 선택했다. 원본을 다시 그리지 않아 픽셀·명암·눈·입·수염의 품질을 유지한다.

## 변경 범위

`Assets/Sprites/Characters/Slimes/{속성}/Slime{속성}MediumLayers.png.meta` 6개의 Face Sprite만 수정했다. Body Sprite, PNG 원본, Sprite ID·GUID·Pixels Per Unit과 Prefab 참조는 유지했다.

| 속성 | 위쪽 제외 높이 | Face 높이 변경 |
| --- | --- | --- |
| 불 | 418px | 887 → 469px |
| 물 | 401px | 887 → 486px |
| 땅 | 405px | 887 → 482px |
| 바람 | 437px | 887 → 450px |
| 번개 | 409px | 887 → 478px |
| 무속성 | 412px | 887 → 475px |

피벗 Y는 `기존 피벗 Y × 기존 높이 / 새 높이`로 보정했다. 눈썹 표시 범위만 줄이고 기존 눈·입의 월드 위치와 크기를 유지하기 위해서다. 소형과 대형, 머리 속성 표시 제거 설정, 피격 Material·Animation은 변경하지 않았다.

## 확인 결과·남은 확인

- 원본 이미지 확인과 알파 행 분석으로 눈썹이 눈·입 위에 분리된 것을 확인했다.
- 6개 메타파일 모두 Face 높이·피벗 외 내용이 동일함을 비교했다.
- 6개 중형 Prefab이 기존 Face Sprite ID·GUID를 계속 참조함을 확인했다.
- 피벗 위치 차이는 계산상 0px이며 검증 허용 오차 0.00001px 이내였다.
- 새 Unity 임포트·실행 화면 검증은 하지 않았다. 에디터에서 재임포트 후 표시를 확인해야 한다. 원본 PNG를 직접 열면 눈썹은 남아 있지만 게임에서 사용하는 Face Sprite 표시 범위에서는 제외된다.
