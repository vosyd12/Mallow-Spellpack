# 레벨업 카드의 스킬 강화 연결

사용자가 작성한 강화 코드는 선택한 워터볼 또는 화염 장판의 `SkillData` 레벨을 한 단계 올린다. 선택 UI의 `Player Skill` 참조가 비어 있었으므로 `Assets/Scenes/IngameScene.unity`의 `CardPanel`을 기존 플레이어 `PlayerSkill`에 연결했다.

첫 버전은 기존 카드 그림과 열기·확정 애니메이션을 사용한다. 워터볼은 버튼 인덱스 0, 화염 장판은 1이다. 인덱스 2인 번개 카드는 레이아웃에 남기고 `Card3`의 CanvasGroup에서 투명도 0.42와 입력 차단을 지정했다. CanvasGroup은 애니메이션이 조절하는 카드 내부 알파와 별도로 적용된다.

## 다음 작업 인수인계

- **결정** — **확정** 첫 버전은 워터볼·화염 장판 강화만 제공하고 기존 카드 연출을 재사용한다. **보류** 번개 카드 보상은 번개 스킬 구현 뒤 연결한다.
- **적용** — `IngameScene`에 보상 참조와 번개 카드 비활성 표시를 저장했다.
- **검증** — 카드 버튼 인덱스, Animator 확정 상태, PlayerSkill 참조와 CanvasGroup 설정을 파일에서 대조했다. 최신 기존 C#의 Unity 컴파일 성공 로그를 확인했다. 이번 씬 변경의 Unity 재생 확인은 남았다.
- **다음 작업** — Play Mode에서 두 카드 각각의 선택, 한 번만 강화, 최대 레벨 제한, 다음 발동 피해량 및 스테이지 전환 후 강화 유지를 확인한다.
- **공유 기준** — 최근 인수인계에 기록된 원격 `main` 기준은 `259aba2`다. 현재 원격 최신 상태는 미확인이다. 이번 씬 및 문서 변경은 현재 작업 폴더에 저장했다.
