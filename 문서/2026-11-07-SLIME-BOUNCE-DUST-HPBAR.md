# 슬라임 두 번째 외형 조정과 HP바 감소 표시 수정

작업일: 2026-11-07. 사용자는 첫 조정보다 과장된 탄력 표현과 착지 먼지를 요청했고, 공격을 받아도 HP바가 줄지 않는 원인 확인을 요청했다.

## 문제·원인·선택

- 외형: 첫 조정으로 높이와 변형을 키웠지만 사용자에게는 부족했다. 기존 Animation 곡선을 더 과장해 코드 구조를 늘리지 않고 눌림·공중 늘어남·착지 반동의 대비를 키웠다.
- 먼지: 실제 도약 높이를 바꾼 뒤에도 SlimeMotion의 먼지용 높이 기준값은 옛 수치였다. 입자 크기·수명·속도와 크기별 개수를 조정하고 기준 높이를 클립과 맞췄다. 공용 풀은 유지한다.
- HP바: 사용자 코드에는 피해 호출과 SetHealth가 연결됐고 기존 `Logs/Editor.log`에 플레이어 HP가 100 → 95 → 90 → 85로 감소하는 기록이 있었다. 반면 공통 HP바와 슬라임 3종의 Fill은 Sliced였다. `fillAmount`를 전달해도 Sliced 이미지는 그 비율로 잘리지 않는다. 공통 프리팹뿐 아니라 개별 프리팹의 Sliced 오버라이드도 Filled로 수정했다.

## 최신 수치

Animation의 로컬 Position Y 최고점이다. 첫 조정 값에서 다시 변경했다.

| 크기 | 일반 도약 전 → 후 | 공격 도약 전 → 후 | 일반 / 공격 먼지 개수 |
| --- | --- | --- | --- |
| Small | 1.4 → 1.8 | 2.4 → 2.8 | 18 / 36 |
| Medium | 1 → 1.3 | 1.8 → 2.1 | 22 / 44 |
| Large | 0.65 → 0.85 | 1.2 → 1.4 | 26 / 52 |

- 준비 마지막 Scale X/Y: 1.30/0.70 → 1.45/0.60.
- 일반 이륙 직후: 0.80/1.25 → 0.70/1.40.
- 일반 첫 착지: 1.35/0.70 → 1.50/0.58. 이후 0.78/1.25 → 1.18/0.84 → 0.94/1.06 → 1/1로 복원한다.
- 공격 첫 착지: 1.45/0.62 → 1.60/0.55. 이륙과 착지 뒤 반동도 강화했다.
- VisualRoot와 HealthBarMotion의 위치 곡선을 맞췄다. HP바는 도약만 따라가고 크기 변형은 받지 않는다.
- 키 시각·클립 길이·이동속도·Duration은 유지했다. 공격의 첫 착지 시점 0.68도 그대로다.

`Assets/Prefab/Effects/LandingDust.prefab`의 변경:

| 항목 | 이전 | 변경 |
| --- | --- | --- |
| Start Lifetime | 0.18~0.32초 | 0.26~0.44초 |
| Start Size | 0.13~0.23 | 0.20~0.34 |
| 수평 속도 기준 | 코드 기본값 1.2 | 프리팹 값 1.65 |
| 수직 속도 기준 | 코드 기본값 0.35 | 프리팹 값 0.55 |
| 공격 확산 배율 | 1.8 | 2 |

일반 먼지는 기존 각 15개에서 표의 개수로 늘렸다. 공격 개수 배율은 2, ParticleSystem 상한은 64로 유지하며 최대 요청은 52개다. 기존 크기 증가·알파 소멸 곡선과 풀 반환 방식은 유지한다. 입자 수·수명 증가에 따른 성능 비용은 새로 측정하지 않았다.

## HP바 수정 위치와 다음 확인법

- `Assets/Prefab/UI/HealthBar.prefab`: Fill의 Image Type을 Filled, 방향을 Horizontal/Left로 설정했다.
- `Assets/Prefab/SlimeSmall/Medium/Large.prefab`: 각각 남아 있던 Fill의 Sliced 오버라이드를 Filled로 변경했다.
- 씬 Player의 Fill은 공통 프리팹을 상속하므로 함께 반영된다. Enemy/Player → HealthBar → Fill 참조도 파일에서 확인했다.

Play 중 HP가 100 → 95로 감소하면 Fill Amount도 1 → 0.95가 되어야 한다. 이후 회피로 공격 범위 밖이면 HP가 줄지 않는 것이 현재 피해 코드의 의도다. 범위 변경으로 무조건 맞게 만드는 수정은 하지 않았다.

## 확인 결과와 한계

파일 기준으로 실행·편집용 Animation 곡선 일치, 상태 경계 자세 연결, HP바 위치 추종, 공통/개별 Filled 설정, 요청 입자 수가 상한 이내인 것을 확인했다. 실제 피해 감소는 작업 전부터 있던 로그의 관측 결과이며 이번 수정의 효과로 계산하지 않는다.

이번 작업은 Animation·프리팹 설정을 수정했고 사용자 C#·씬·Controller를 수정하지 않았다. Unity 재생·MCP·새 캡처·성능 측정은 하지 않았다. 더 탄력 있는 외형과 먼지, 줄어드는 HP바가 예상 결과이며 실제 화면 결과는 아직 확인하지 않았다. 이전 Sprite 형식 경고의 누적 로그만으로 현재 재발 여부를 판단하지 않는다.
