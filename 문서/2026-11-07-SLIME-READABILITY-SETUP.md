# 슬라임 외형 확대·속성 장식 분리·착지 효과 연결

작성일: 2026-11-07

후속 수정: 이 기록의 최초 Dust 구성에는 아틀라스 표시·바람 회전 설정 오류가 있었다. 최신 착지 효과와 실제 MCP 확인 결과는 [셰이더·표시 수정 기록](2026-11-07-ELEMENT-LANDING-SHADER-FIX.md)을 따른다. 아래 내용은 최초 연결 당시의 구조·확인 범위다.

## 요청과 문제

전체 맵 구도에서 Small의 장식은 작고, 강한 압축·늘어남 때문에 불꽃·소용돌이 등 속성 표시가 몸과 함께 변형됐다. 사용자는 외형 확대와 속성별 착지 효과를 제안했으며, 확대·장식 변형 분리·착지 효과를 함께 적용하는 조합을 승인했다. 코드 작성은 사용자가 주도하고 AI는 이미지·Prefab·Animation·씬 연결을 담당했다.

## 선택과 변경

- 변경 직전 크기에서 Small은 1.6배, Medium·Large·플레이어는 1.5배로 확대했다. Small의 기존 20% 확대를 취소한 뒤 적용한 값이 아니라 그 상태에 추가로 적용한 배율이다. 이전 원형 대비 가로폭은 Small 1.92배이며 최신 규칙은 GAME_DESIGN을 따른다.
- 루트 대신 `ReadabilityScale`을 확대했다. Collider·Rigidbody2D·이동 속도·공격 범위·Stage·카메라는 유지했다. 플레이어는 씬의 활성 `Visual`만 확대했다.
- 불·물·땅·바람·번개에 몸·장식·착지 입자 아틀라스를 각 1개씩 준비했다. 같은 속성의 세 크기는 몸·장식 이미지를 공유하고 기존 개별 얼굴 이미지는 유지한다. 무속성은 기존 몸·얼굴을 사용한다. 새 아틀라스는 기존 픽셀 스타일을 기준으로 다시 생성했으므로 원본 픽셀을 그대로 잘라낸 것은 아니다.
- 몸의 압축·늘어남을 `BodyMotion`으로 옮기고 장식에는 적용하지 않았다. 장식은 도약과 몸의 세로 배율에 따른 머리 위치를 추종한다. 장식을 몸에 계속 포함하거나 모든 변형을 약하게 만드는 대신, 기존 보잉 모션과 속성 형태를 함께 유지하는 방법을 선택했다.
- 그림자 크기·바닥 위치를 확대 비율에 맞추고, HP바는 확대된 머리 장식을 가리지 않도록 높이를 올렸다. HP 계산·잔상 코드는 변경하지 않았다.

## Hierarchy와 조절 위치

```text
VisualRoot                         # 기존 도약 위치
└ ReadabilityScale                 # Small 1.6 / Medium·Large 1.5
  ├ BodyMotion                     # 기존 압축·늘어남
  │ └ Visual
  │   ├ Body
  │   └ FaceMotion                 # 기존 얼굴 지연 흔들림
  └ ElementAnchor                  # Variant별 머리 높이
    └ ElementMotion                # 몸 높이를 따라가는 위치 곡선
      └ ElementVisual              # 비율을 유지하는 장식
```

기본 Prefab 3개가 구조를 제공하고 속성 Variant 18개가 이미지·장식 높이·표시 크기를 지정한다. 기존 얼굴 경로가 변경되어 관련 Animation 9개의 실행 곡선·편집 곡선·바인딩 경로를 함께 갱신했다. 전투 스크립트의 참조는 유지했다.

## 속성별 착지 효과

`Assets/Prefab/Effects/LandingDust{속성}.prefab` 6개를 `SampleScene`의 `LandingDustPool._elementDusts`에 등록했다. 배열은 Inspector 설정용이며 실행 중 속성 조회는 사용자 코드의 `Dictionary<Element, ObjectPool<LandingDust>>`가 담당한다.

| 속성 | 외형·움직임 | 입자 수명 |
| --- | --- | --- |
| Fire | 주황 불씨, 위로 상승 | 0.18–0.34초 |
| Water | 파란 물방울, 퍼졌다 하강 | 0.22–0.38초 |
| Earth | 갈색 돌조각, 낮은 확산·중력 | 0.18–0.32초 |
| Wind | 민트 곡선 입자, 궤도 회전 | 0.18–0.30초 |
| Lightning | 노랑·보라 지그재그, 짧게 표시 | 0.07–0.14초 |
| Pure | 기존 먼지 이미지·기본 확산 | 기존 0.26–0.44초 |

일반·공격 착지는 `SlimeMotion.SpawnLandingDust()` → `LandingDustPool.Play(element, ...)` → `LandingDust.Play(...)` 순서다. 사용자가 수정한 세 C# 파일의 호출·매개변수가 일치함을 확인했으며 이번 작업에서 C#은 수정하지 않았다. 입자 이미지는 아틀라스의 UV 범위를 재질에서 선택하며, 색상과 이동 속도만 바꾼 동일한 먼지로 대체하지 않았다.

속성당 6개씩 총 36개를 예열한다. `maxSize = 16`은 속성당 비활성 보관 한도이며 동시 활성 개수의 제한은 아니다. 이동 중 계속 방출하지 않고 기존 착지 시점에만 재생한다. 모든 효과는 기존 자식 착지 파동을 상속한다. 크기별 입자 개수와 공격 확산 보정은 유지하며 속성 피해·상성은 추가하지 않았다.

## 확인 결과와 남은 확인

- 파일 확인: 18개 크기·속성 조합, 6개 효과의 컴포넌트 참조, Hierarchy 경로, Animation 바인딩, 예약/중복 ID, 기존 얼굴 참조를 대조했다. C# 해시와 물리·전투 컴포넌트 직렬화 데이터가 변경되지 않았다.
- Unity 확인: 별도 복사본의 Unity 6000.5.10f1에서 기본 3개·Variant 18개·효과 6개, 총 27개 Prefab의 네이티브 임포트와 정상 종료를 확인했다. C# 컴파일 오류·Prefab 손상 오류는 검출되지 않았다. 복사본은 로컬 uGUI와 최소 모듈 구성이므로 원본 프로젝트 전체의 그래픽·패키지 검증을 대신하지 않는다.
- 미확인: 이번 변경 후 원본 씬의 Play Mode·속성별 실제 재생·군집 중 식별성·모바일 화면·성능 수치는 검증하지 않았다. MCP·Notion도 사용하지 않았다. 식별성 향상과 프레임 비용 절감은 실측 결과로 주장하지 않는다.
- 사용자 확인 대상: Small의 속성 식별, 장식이 머리에서 떨어지거나 얼굴을 가리는지, HP바 높이, 여섯 착지 효과의 크기·잔류 시간, 반복 착지 시 풀 반환.
