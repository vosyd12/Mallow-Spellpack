# 슬라임 크기별 체력과 왕관 보스 체력 연결

이전에는 일반 대형 원본에 최대 체력 500이 저장돼 속성별 대형 슬라임도 500을 상속했다. 사용자 작성 `Enemy.Awake()`는 `EnemyState.Size`와 `IsBoss`를 기준으로 체력을 계산하지만, 왕관 보스 프리팹에는 새 보스 플래그가 연결돼 있지 않았다.

`Assets/Prefab/SlimeSmall.prefab`, `SlimeMedium.prefab`, `SlimeLarge.prefab`에 실제 크기를 지정하고 `IsBoss`를 껐다. `Assets/Prefab/Slimes/StageBossSlime.prefab`에만 `IsBoss` 오버라이드를 켰다. 보스의 크기는 `Large` 원본에서 상속한다. 네 프리팹에서 예전 `_maxHP` 직렬화 값을 정리했다. 사용자가 작성한 초기화 코드와 기존 프리팹 GUID를 사용한다.

## Play Mode 검증

- Unity 6000.5.10f1의 `IngameScene`을 MCP로 확인했다. 첫 재생에서 Unity가 저장 전 프리팹 상태를 읽어 보스가 HP 30으로 생성됐다. 대상 프리팹을 다시 임포트한 뒤 스포너가 가리키는 보스의 `Size = Large`, `IsBoss = true`를 Unity에서 확인했다.
- 일반 Variant 18종을 실제 생성해 소형 30, 중형 50, 대형 100과 생성 직후 체력바를 확인했다. 처치 목표를 채워 실제 Stage 스포너로 생성한 왕관 보스의 체력은 500이었다.
- 다른 공격과 대상 이동을 Play Mode에서 잠시 제어하고 화염 장판을 한 번 발동했다. 범위 안의 보스·소형·중형·대형이 각 5 피해를 4회 받았고, 범위 밖 소형은 체력이 유지됐다. 실제 잔여 HP와 각 개체의 체력바가 일치했고, 상단 보스 게이지도 100%에서 96%로 줄었다.
- 보스를 처치하자 상단 게이지가 0이 됐다. 사망 모션 후 타이머가 숨겨지고 2스테이지에 진입했다. 종료 시 Unity 콘솔 오류는 0건이었다.

## 다음 작업 인수인계

- **결정** — **확정** 같은 크기의 일반 슬라임은 기본 최대 체력을 공유한다. 현재 사용자 설정은 소형 30, 중형 50, 대형 100, 왕관 보스 500이다.
- **적용** — 원본 프리팹 세 개의 크기와 왕관 보스 Variant의 플래그를 저장했다.
- **검증** — 파일의 프리팹 값과 스포너 GUID를 대조한 뒤 Unity 재임포트와 Play Mode에서 초기 HP, 장판의 다중 대상 피해, 체력바와 스테이지 전환을 확인했다.
- **다음 작업** — 이번 체력 연결의 미검증 항목은 없다. 장판 피해량과 보스 제한시간은 전투 밸런스를 조정할 때 함께 검토한다.
- **공유 기준** — 이전 보스전 인수인계에 기록된 원격 `main` 기준은 `259aba2`다. 현재 폴더에서 Git 메타데이터를 조회할 수 없어 원격 최신 상태는 미확인이다. 이번 프리팹과 문서 변경은 현재 작업 폴더에 저장했다.
