# 뱀서류 전환과 5스테이지 검증 인수인계

기존 초원에서 직접 이동과 자동 공격을 조합하고, 마법 선택으로 한 판의 전투 방식이 달라지는지 확인한다. 첫 검증 범위는 Stage 1~5다. 현재 작업 씬은 `Assets/Scenes/IngameScene.unity`이고 Unity 버전은 `6000.5.10f1`이다. [11월 25일 기획 전환안](https://app.notion.com/p/423a9adf06de8122aa87de378f84e644)

## 방향과 고민한 사항

- **확정** — 방치형 RPG 중심에서 마법 성장 중심의 뱀서류로 전환한다. 초기안은 자동 전투로 자원을 모으고 수동 레벨업·강화·배낭 배치를 결정하는 흐름이었다. 현재는 적을 피하고 위치를 잡는 판단이 생존을 바꾸고, 카드로 바뀐 마법을 다음 적 무리에서 체감하는 흐름을 우선한다. 11월 24일에 검토한 짧은 1인 던전과 입장 전 전투력 표시보다 기존 스테이지·보스 로직을 활용한 5스테이지 검증을 앞세운다.
- **확정** — 경험치가 차면 카드 선택을 자동으로 열고 확정 연출이 끝날 때까지 전투 시간을 멈춘다. 초과 경험치는 남겨 다음 레벨업에 사용한다. 전투 HUD는 기존 레벨 패널, 진행 바와 보유 스킬 아이콘처럼 플레이에 필요한 표시 위주로 줄인다. 스킬 아이콘은 읽기 전용이고, 쿨타임은 원형 덮개와 남은 초로 읽는다. 조이스틱은 평소 숨기고 터치한 위치에만 표시한다.
- **검토 중** — 사망 또는 Stage 5 클리어 시 도전을 종료하고, 도달 단계·생존 시간·빌드를 정산한 뒤 다시 시작하는 안을 검토한다. 현재 사망과 보스 타임아웃은 같은 스테이지 재시작으로 연결돼 있다. 새 도전 종료 규칙, 판 내부에서 초기화할 항목, 스테이지 전환 시 HP와 보상은 판단이 필요하다.
- **검토 중** — 워터볼의 다중 발사·관통, 화염 장판의 범위 확대·만료 폭발을 첫 특성 후보로 둔다. 피해량만 올리는 강화보다 적이 모이는 위치와 이동 경로에 따라 특성의 효율이 달라지는지 본다. 스테이지별 적 동시 상한·생성 속도·행동 구성으로 압박을 조절한다. 보스 단독 등장은 광역·관통 빌드의 가치를 약하게 만들 수 있어 일반 적 동시 등장과 타이머를 검토한다.
- **검토 중** — 환생 스탯은 판 밖의 기초 능력, 스킬 트리는 빌드 방향, 카드는 판 안의 선택을 맡는 방향이다. 트리가 특성을 해금하면 카드 후보가 늘어 원하는 특성이 나오기 어려워질 수 있고, 특성을 영구 적용하면 판 안에서 선택할 이유가 줄 수 있다. 점수는 도달·클리어 단계 중심으로 검토하며, 낮은 단계에서 빠르게 사망하는 반복이 유리해지는지도 확인한다.
- **보류** — 정식 환생·스킬 트리, 배낭·합성·펫·오프라인 정산, 전투력 표시, 신규 맵·마법과 5스테이지 이후 확장. 워터볼과 화염 장판의 특성을 바꿔 플레이했을 때 생존·돌파·재도전의 결과가 달라지는지 먼저 본다.

## 적용과 확인 범위

| 작업 | 현재 구현과 확인 결과 | 남은 확인 |
| --- | --- | --- |
| 왕관 슬라임 공격 | 수동 이동 뒤에는 일반 점프만 반복하거나 공격 시작 때의 방향으로 뛰어 빗나갔다. `SlimeMotion.cs`에서 보스가 실제로 이륙할 때 방향을 한 번 갱신하고, 보스 프리팹의 공격 시작 거리를 2→3으로 조정했다. 착지 판정은 1.6이다. Unity MCP Play Mode에서 2.7 거리 공격 진입, 이륙 시 방향 갱신, 정지 대상 5 피해와 이동 회피를 확인했다. | 자유 전투와 실기기에서 공격 빈도·회피 여유를 조정한다. |
| 보스 15초 타임아웃 | 0초에서 표시 숫자만 멈추던 원인은 종료 분기 누락이었다. `Stage.cs`에서 시간 만료 시 기존 재시작 흐름을 사용한다. Play Mode에서 전투 차단, 보스·타이머 정리, 처치 게이지 0, 같은 1스테이지 일반 전투 복귀와 플레이어 HP 유지를 확인했다. | 새 5스테이지 검증 빌드에서 시간 초과를 어떤 결과로 처리할지 정한다. |
| 플레이어 중심 카메라 | `PlayerCameraFollow.cs`를 메인 카메라에 붙여 `Player` 루트의 X·Y를 따라가게 했다. `Stage.cs`가 보스 줌 동안 추적을 끄고 카메라 위치·배율 복원 뒤 다시 켠다. 현재 직교 카메라 크기는 5다. 씬 참조와 Unity 씬 임포트를 확인했다. | 이동 중 중앙 유지와 떨림, 맵 끝의 배경 노출, 보스 줌 이후 추적 복귀를 Play Mode에서 확인한다. |
| 투명한 이동 조이스틱 | `FloatingJoystick.cs`와 씬을 기존 `Player/Move`의 가상 왼쪽 스틱에 연결했다. 감지 영역은 화면 오른쪽 약 55%, 아래쪽 약 34%에 비례한다. 이전 고정형 스틱은 좁은 Free Aspect에서 화면 밖으로 나갔다. 이동이 멈췄을 때는 드래그 값이 이미 액션에 들어오고 있었고, 삭제된 레벨업 버튼의 참조 때문에 `Player.Awake()`가 예외로 종료됐다. Play Mode에서 임시 참조를 채우고 `Player`를 다시 켠 뒤 5.16유닛 이동, 해제 후 정지·숨김을 확인했다. 이후 `PlayerInfo.cs`에 버튼이 있을 때만 갱신하는 조건이 들어갔다. | 수정된 저장 씬에서 임시 참조 없이 드래그·재터치·해제, 멀티터치와 실기기 조작을 확인한다. |
| 자동 레벨업과 시간 정지 | `Player.cs`가 경험치 충족 시 자동 레벨업하고, `LevelUpCardPanel.cs`가 카드 표시 중 시간 배율을 0으로 설정한 뒤 닫힐 때 복원한다. 기다리는 동안 추가 레벨업을 차단한다. C# 컴파일과 `FinishOpening`·`FinishConfirmation` 애니메이션 이벤트는 확인했다. | 저장된 `CardPanel` Animator가 아직 `Normal`이다. `Unscaled Time`으로 바꾸고 자동 출현·선택·확정·전투 재개를 확인한다. 마지막 일반 적 처치와 레벨업이 겹칠 때 보스 등장 시작을 미루는 조건도 `Stage.cs`에 남아 있다. |
| HUD 배치와 스킬 표시 | 상단 `ProgressBars` 아래에 보스 게이지와 EXP 바를 쌓았다. 보스 게이지는 `StageInfo`, EXP 바는 기존 `PlayerInfo`를 사용한다. 두 바에 직각 테두리를 적용하고 높이는 각각 24와 12로 설정했다. 레벨 패널 아래의 워터볼·화염 장판은 버튼 없이 `SkillSlotUI`로 연결했다. 최신 씬에 직각 설정과 스킬 참조가 있으며 Unity 임포트 로그를 확인했다. | 현재 배치는 임시안이다. 세로 Game View에서 크기·여백·가독성과 실제 쿨타임 표시를 확인한 뒤 최종 배치를 정한다. `HUDCanvas`의 `Match`는 여전히 0.5이며, 너비 기준 배율은 이전 Play Mode에서 비교한 시안이다. |

## 다음 작업 인수인계

- **결정** — **확정** 뱀서류 전환, 기존 스테이지·보스 재사용, Stage 5까지 검증, 자동 카드 선택 중 전투 정지. **검토 중** 도전 종료·정산과 재도전, 특성 후보와 적 밀도, 보스 타임아웃과 HUD 최종 배치. **보류** 정식 환생·스킬 트리와 확장 시스템.
- **적용** — 카메라 추적, 투명 조이스틱, 보스 공격과 타임아웃, 직각 진행 바와 스킬 표시가 현재 씬·코드에 들어 있다. 자동 카드 선택과 시간 정지는 C#에 들어 있다.
- **검증** — 보스 공격·타임아웃과 조이스틱 임시 재현은 앞선 Unity MCP Play Mode에서 확인했다. 이번에는 현재 파일과 Unity 컴파일·임포트 기록을 대조했다. 카드 정지·재개, 최신 HUD, 카메라와 실기기 조작의 통합 재생은 남아 있다.
- **다음 작업** — 먼저 `CardPanel`의 `Unscaled Time`과 보스 등장 대기 조건을 연결하고 카드 선택까지 한 번 재생한다. 이어 세로 화면에서 조이스틱·카메라·HUD를 확인한다. 다음 검증 빌드의 Stage 5 종료, 사망·타임아웃 결과와 판별 초기화 규칙은 사용자 결정을 기다린다.
- **공유 기준** — 기획 전환안이 기록한 이전 GitHub `main` 검토 기준은 `05685c3`이다. 현재 작업 폴더에서는 Git 이력을 조회할 수 없어 최신 원격 커밋과 11월 25일 변경의 반영 여부는 확인되지 않았다. 이번 문서 정리와 전투·입력·HUD 연결은 현재 작업 폴더 기준이다.
