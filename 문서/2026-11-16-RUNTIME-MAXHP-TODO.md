# 실행 중 MaxHP 변경과 체력 표시 동기화 과제

작성일: 2026-11-16. 사용자 보고와 Player·HealthBar·PlayerInfo 코드를 대조해 수정 과제로 등록했다. 코드·씬은 변경하지 않았으며 MCP·새 실행 검증은 수행하지 않았다.

## 보고된 현상

Inspector의 MaxHP를 10으로 두고 Play에 진입한 뒤 100으로 변경해도 체력바는 가득 찬 상태를 유지했다. 사용자는 두 번 피격 후 사망하는 동작도 이전과 같다고 보고했다. 체력바 표시와 실제 체력이 실행 중 변경한 설정을 어떻게 반영하는지 파악하기 어려운 상태다.

## 현재 흐름과 원인

- Player.Awake는 `_player.HP = _maxHP`로 현재 HP를 한 번 초기화한다. 따라서 시작값이 10이면 현재 HP도 10이다.
- Inspector에서 `_maxHP`만 변경해도 Awake가 다시 실행되거나 현재 HP가 자동으로 100이 되지 않는다. 현재 Player에는 해당 변경을 받아 처리하는 코드가 없다.
- HealthBar는 Player를 감시하지 않고 `SetHealth(currentHP, maxHP)`로 전달받은 비율을 표시한다. 이 호출은 초기화·피격·부활에 있으며 MaxHP 필드 편집 직후에는 호출되지 않는다.
- 따라서 편집 직후 체력바가 이전 10/10 비율을 유지하고 실제 현재 HP도 10에 머무르는 것은 현재 코드로 설명된다. 다음 피격에서는 변경된 최대 HP를 전달하므로 표시가 바뀔 수 있다. 이 후속 화면은 이번에 재현 검증하지 않았다.

UI만의 오류로 단정하지 않고 **최대 HP 설정·현재 HP 상태·UI 갱신 전달의 연결 문제**로 관리한다. 설정 변경만으로 현재 HP도 전부 회복될 것이라는 전제는 아직 게임 규칙으로 확정하지 않는다.

## 수정 목표와 미정 사항

실행 중 최대 HP 변경을 지원하고 현재 HP와 체력바가 정한 정책대로 함께 갱신되게 한다. 최대 HP를 줄였을 때 현재 HP가 범위를 넘지 않도록 처리하고 표시·피해·사망 판정에 같은 현재/최대 값이 사용되는지 확인한다.

현재 HP 절대량 유지, 비율 유지, 최대치로 회복 중 어떤 정책을 적용할지는 미정이다. 예를 들어 10/10에서 최대 HP만 100으로 늘릴 때 10/100을 표시할지 100/100으로 회복할지부터 결정해야 한다. Inspector 시험용 변경과 실제 성장/장비에 따른 변경의 적용 범위도 착수 시 구분한다.

변경을 한 곳에서 처리하고 UI에 전달하는 방식은 해결 후보이며, 매 프레임 감시나 특정 이벤트/함수 구현을 확정하지 않았다. 기대 결과는 일관된 체력 상태와 표시이며 실제 개선·성능 수치는 없다.

## 레벨업의 현재 범위

현재 TryLevelUp은 경험치 조건 검사·차감, 캐릭터 레벨 증가, 필요 경험치 증가와 HUD 갱신을 수행한다. PlayerInfo는 경험치에 따라 버튼의 클릭 가능 상태를 표시한다. 스킬 획득·성장·카드 선택 연결은 아직 없다. 따라서 레벨업 전체가 미구현인 것과 기본 레벨 상승만 구현된 상태를 구분한다. 이번에는 레벨업 코드를 바꾸거나 카드 기능에 착수하지 않았다.

## 확인할 항목

최대 HP 증가/감소, 피해를 받은 상태와 사망 상태에서의 변경, 체력바 잔상, 다음 피격과 부활 후의 표시를 확인한다. 사용자 보고와 파일로 확인한 원인만 기록했으며 새 Play·컴파일·수정 후 검증 결과는 없다.

## 추가 수정 요청: HealthBar 외형 개선

사용자는 HealthBar를 더 세련된 외형으로 개선할 것을 요청했다. 기능 동기화 문제와 별도의 시각 개선 과제로 등록하며, 현재 캐릭터·HUD와 어울리는 스타일과 실제 게임 크기에서의 가독성을 검토한다. 테두리·색·크기·잔상 표현의 구체적인 변경안은 아직 정하지 않았다. 디자인 제작·코드·씬 수정은 진행하지 않았으며 시각적 개선 결과도 미확인이다.
