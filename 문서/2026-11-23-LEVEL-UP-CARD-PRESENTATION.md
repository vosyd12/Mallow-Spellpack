# 레벨업 카드 UI와 선택 연출

## 결정과 적용

- **확정** — 레벨업 성공 직후 카드 세 장이 차례로 뒤집혀 등장한다. 선택한 카드가 확대되고 뒤에서 금빛 후광이 일렁인다. 선택하지 않은 두 장은 하단부터 바스러지고 파편은 아래로 떨어진다. 선택 카드는 후광과 함께 서서히 사라지며 선택 중에도 전투는 계속된다.
- **적용** — 크림색 바탕, 올리브색 윤곽과 잎 장식을 기존 HUD에 맞췄다. 워터볼과 화염 장판에는 기존 스킬 그림을 사용했다. 세 번째 번개 카드는 연출 확인용이다.
- **검토 중** — 실제 세 번째 스킬과 카드 후보·보상 규칙. **보류** — UI에서 캐릭터로 이동하는 에너지와 월드 성장 VFX.

## 구현과 확인

IngameScene에서 CardPanel이 자신을 꺼 레벨업 성공 이벤트를 받지 못하던 연결을 고쳤다. 카드만 담는 CardRoot를 만들어 표시를 제어하고, 기존 레벨업 버튼에 CanvasGroup을 연결했다. 기존 카드 버튼 세 개의 선택 인덱스와 패널 Animator 상태를 연결했다. 기존 CardOpen.anim의 접힘 곡선을 패널의 등장 키에 반영해 카드별 시차와 앞뒷면 전환을 추가했다. 기존 C#과 원본 카드 클립을 유지했다.

Assets/UI/LevelUpCards에 카드와 제목 이미지, 후광 머티리얼, UV 왜곡·방향성 디졸브·낙하 파편을 구운 스프라이트 시트를 추가했다. Assets/Animations/UI/LevelUpCards에는 약 0.56초의 등장 클립, 선택 위치별 약 1.28초의 확정 클립 세 개와 컨트롤러가 있다. 파편은 2D UI 플립북으로 재생하며 Android와 iOS용 VFX 시트에는 ASTC 가져오기 설정을 적용했다.

Unity 6000.5.10f1의 IngameScene Play Mode에서 버튼 클릭 이벤트로 레벨업과 세 카드의 선택을 각각 실행했다. 등장 중 입력 차단, 확정 뒤 연타 차단, 선택한 카드의 후광, 나머지 두 카드의 디졸브, 닫힘 뒤 레벨업 버튼 잠금 해제, 정상 속도의 게임 시간 진행을 확인했다. 1920×1080과 900×1600 Game View에서 세 카드가 화면 안에 있고 각 카드 중앙의 레이캐스트가 해당 버튼을 가리키는 것을 확인했다. 카드 제목과 스테이지 HUD가 가로 화면에서 겹쳐 카드 묶음의 높이를 조정했다. 최종 가로 화면에서 두 영역 사이 약 35픽셀의 간격을 확인했다. 모바일 실기기 성능은 확인 전이다.
